# 31. 下一个排列（Next Permutation）

难度：中等

## 题目描述

整数数组的一个排列，是将其所有成员以序列或线性顺序排列。

整数数组的下一个排列，是指其整数的下一个字典序更大的排列。如果数组的所有排列根据字典序从小到大排列，那么下一个排列就是紧接在当前排列之后的排列。

如果不存在字典序更大的排列，则必须把数组重排为字典序最小的排列，即按升序排列。

给定整数数组 `nums`，找出它的下一个排列。

必须原地修改数组，并且只允许使用常数额外空间。

## 示例

示例 1：

```text
输入：nums = [1,2,3]
输出：[1,3,2]
```

示例 2：

```text
输入：nums = [3,2,1]
输出：[1,2,3]
```

示例 3：

```text
输入：nums = [1,1,5]
输出：[1,5,1]
```

## 约束

- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 100`
