# 287. 寻找重复数（Find the Duplicate Number）

难度：中等

## 题目描述

给定一个包含 `n + 1` 个整数的数组 `nums`，其中每个数字都在 `[1, n]` 范围内，因此至少存在一个重复的整数。

假设 `nums` 中只有一个整数重复出现，返回这个重复数。这个整数可能出现两次或多次，其余整数均只出现一次。

解决方案必须满足：

- 不修改数组 `nums`
- 只使用常量级 `O(1)` 额外空间

## 示例

示例 1：

```text
输入：nums = [1,3,4,2,2]
输出：2
```

示例 2：

```text
输入：nums = [3,1,3,4,2]
输出：3
```

示例 3：

```text
输入：nums = [3,3,3,3,3]
输出：3
```

## 约束

- `1 <= n <= 10^5`
- `nums.length == n + 1`
- `1 <= nums[i] <= n`
- `nums` 中只有一个整数出现两次或多次，其余整数均只出现一次

## 进阶

- 证明 `nums` 中至少存在一个重复数字
- 设计时间复杂度为 `O(n)` 的解决方案
