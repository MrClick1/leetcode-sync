## 前缀和是什么

统一采用这个定义：`prefix[i]` 表示原数组前 i 个元素的和，即下标区间 `[0, i)` 的和。

```text
nums       = [2, 3, -1, 4]
prefix     = [0, 2, 5, 4, 8]
prefix 下标   0  1  2  3  4
```

`prefix[0]=0` 表示空前缀；`prefix[3]=4` 包含 nums[0]、nums[1]、nums[2]，不包含 nums[3]。

基础 C++ 写法：

```cpp
int n = static_cast<int>(nums.size());
vector<long long> prefix(n + 1, 0);
for (int i = 0; i < n; ++i) {
    prefix[i + 1] = prefix[i] + nums[i];
}
```

通用模板用 long long 降低累加溢出的风险；实际仍需按题目数据范围选择类型。

## 如何计算区间和

闭区间 `[l, r]` 的和为：

```cpp
long long sum = prefix[r + 1] - prefix[l];
```

前 r+1 个元素去掉前 l 个元素，剩下的正好是 nums[l] 到 nums[r]。例如上面的 `[1,3]`：`prefix[4]-prefix[1]=8-2=6`，对应 `3+(-1)+4`。

边界检查：l=0 时减 prefix[0]；l=r 时得到单个元素；整个数组的和为 prefix[n]。不要混用另一种“prefix[i] 包含 nums[i]”的定义。1480 的返回数组采用包含当前元素的定义，与这里多放一个空前缀的模板相差一位。

预处理 O(n)，单次区间查询 O(1)，q 次查询合计 O(n+q)，保存前缀数组需要 O(n) 空间。普通前缀和更适合原数组不变的多次查询；修改一个元素会影响它后面的前缀。

## 进阶题如何建立联系

560：如果 `prefix[r]-prefix[l]=k`，就要寻找此前的 `prefix[l]=prefix[r]-k`。哈希表保存出现次数，初始空前缀出现一次；先查询再插入当前前缀，避免把空区间算进去。

525：将每个 0 视为 -1，0 和 1 数量相等就转换为区间和为 0。求最长长度时保存同一前缀值最早出现的位置，而不是出现次数。

974：两个前缀和对 k 的规范化余数相同，它们的差就能被 k 整除。对正 k，C++ 中可用 `(sum % k + k) % k` 统一负数余数。

304：用 `prefix[i][j]` 表示前 i 行、前 j 列的矩形和。矩形查询需要“大矩形减上方减左方，再补回被减两次的左上方”；到这题再画图推导。

## 常见易错点

- 前缀和处理连续区间，不是任意挑选的子序列。
- 前缀数组开 n+1 个位置，区间右端点使用 r+1。
- 数组中可以有负数，前缀和不一定递增，不能直接依赖单调性二分或套用正数滑动窗口。
- 求方案数通常保存频次；求最长区间通常保存最早位置。先明确哈希表 value 的含义。
- 是否需要哈希表、是否保存整个 prefix 数组，由问题决定；不要把所有前缀和题都写成同一模板。
