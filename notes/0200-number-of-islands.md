# 200. 岛屿数量 —— 复盘笔记

状态：✅ 已解决（BFS，O(mn) 时间）

## 遇到的问题

1. **BFS 忘写 `que.pop()`** → 队列只进不出 → 死循环，LeetCode 上直接 TLE
2. **`break` 只跳出内层 j 循环** → 一轮扫描把多个岛的起点同时入队 → 多岛被合并计数（示例 2 期望 3 得 1）
3. **按行扫描时提前 break** → 同一行后面的岛被漏掉（单行 "101" 期望 2 得 1）

## 解题要点

- 两层结构：外层 for 扫每个格子找未访问的 `'1'`；内层 while BFS 淹没整座岛
- **找到起点后不要 break**，BFS 结束后继续扫描后面的格子
- **入队时立即标记 visited**（不是出队时），保证每个格子最多入队一次 → O(mn)
- BFS 模板：`front → pop → 扩展四个方向 → 入队并标记`
- 小坑：Windows 终端是 GBK 代码页，测试程序输出中文会乱码，输出语句用英文

## 延伸练习

- [ ] **沉岛法**：BFS 时把访问过的格子直接改成 `'0'`，省掉 visited 数组，额外空间降到 O(1)
- [ ] **DFS 版**：用递归或显式栈写一遍同样思路，练习"BFS 之外怎么做"

## 复杂度

- 时间：O(mn)
- 空间：O(mn)（visited 数组；沉岛法可降到 O(1)）
