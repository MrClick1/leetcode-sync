# 54. 螺旋矩阵 —— 复盘笔记

状态：✅ 已解决（O(1) 额外空间）

## 遇到的问题

1. 一开始没有"剥洋葱"的心智模型，不知道每轮怎么写、边界怎么收缩
2. 只剩一行/一列时，下边和左边会重复走已经走过的格子（单行矩阵会往返走两遍）

## 解题要点

- 四个边界：`top / bottom / left / right`，表示当前未剥掉的矩形区域
- 每轮四段路：上边 → 右边 → 下边 → 左边
- 每走完一边立刻收缩对应边界：`top++` / `right--` / `bottom--` / `left++`
- 两个关键守卫（防重复遍历）：
  - 走下边前：`if (top <= bottom)`
  - 走左边前：`if (left <= right)`
- 循环条件：`while (top <= bottom && left <= right)`

## 复杂度

- 时间：O(mn)（每个元素恰好入队一次）
- 空间：O(1)（除输出数组外）
