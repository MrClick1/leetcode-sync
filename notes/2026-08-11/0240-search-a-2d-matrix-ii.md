# 240. 搜索二维矩阵 II —— 复盘笔记

状态：✅ 2026-10-06 用户右上角阶梯搜索二刷已力扣通过（O(m+n) 时间，O(1) 空间）。

## 2026-10-06 通过代码

```cpp
class Solution {
public:
    bool searchMatrix(vector<vector<int>>& matrix, int target) {
        int m = (int)matrix.size();
        int n = (int)matrix[0].size();
        int row = 0;
        int col = n - 1;

        while (row < m && col >= 0) {
            if (matrix[row][col] == target) {
                return true;
            } else if (matrix[row][col] < target) {
                // 排除剩余区域的当前行
                ++row;
            } else {
                // 排除剩余区域的当前列
                --col;
            }
        }
        return false;
    }
};
```

循环入口的候选区域是行 `[row,m-1]`、列 `[0,col]`。当前位置是该区域的右上角：当前值小于目标，则它左边的数也小于目标，排除当前行；当前值大于目标，则它下方的数也大于目标，排除当前列。已经排除的右侧列和上方行不需要再考虑。

因此注释中的“这一行/列都不用考虑了”指剩余搜索区域内的部分，不是声称原始整行/列中的所有元素都满足同一大小关系。每次移动都会使候选区域缩小，离开矩阵边界时返回 false。

## 遇到的问题

1. 一开始想用二分，但发现这个矩阵**行与行之间没有全局顺序**（不像 74 题），不知道该怎么缩小范围
2. 卡在"每一行都要二分、范围怎么定"上

## 解题要点

- 和 74 题区分开：
  - 74：行首严格大于上一行行尾，可以拉平成一维做二分
  - 240：只有行内/列内有序，行间无全局顺序，不能拉平
- **右上角阶梯法**（左下角对称也可）：
  - 当前值 `> target` → 整列排除，`col--`
  - 当前值 `< target` → 整行排除，`row++`
  - 相等 → 找到
- 为什么右上角特殊：它是**剩余区域当前行最大、当前列最小**，所以每次比较都能排除候选区域的一行或一列
- 最多走 m+n 步 → O(m+n) 时间，O(1) 空间
- 备选方案：逐行二分 O(m log n)。与阶梯法的效率比较取决于矩阵形状；例如只有一行时，直接二分更合适。

## 复杂度

- 时间：O(m+n)
- 空间：O(1)
