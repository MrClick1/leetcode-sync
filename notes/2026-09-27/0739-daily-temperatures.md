# 739. 每日温度

状态：2026-09-27 用户确认 LeetCode 提交通过，代码审阅正确。本轮在网页端练习，未创建本地题目脚手架或重新运行测试。

## 栈里保存什么

栈保存“还没找到后面第一个更高温度的日期下标”。保存下标才能用 `i - topIdx` 算等待天数。

从栈底到栈顶，下标递增，对应温度单调不增（允许相等）。原注释“最大栈”容易让人误以为只保留最大值，应改为“单调栈，保存尚未找到更高温度的下标”。

较低的温度也要入栈，因为它同样需要等待自己的答案。每一天都会入栈一次。

## 最终通过代码

保留用户实现，仅调整栈的注释。

```cpp
class Solution {
public:
    vector<int> dailyTemperatures(vector<int>& temperatures) {
        int n = (int)temperatures.size();
        stack<int> stk;  // 下标栈；对应温度从栈底到栈顶单调不增
        vector<int> res(n, 0);

        stk.push(0);
        for (int i = 1; i < n; ++i) {
            while (!stk.empty() && temperatures[i] > temperatures[stk.top()]) {
                int topIdx = stk.top();
                res[topIdx] = i - topIdx;
                stk.pop();
            }

            // 今天也需要等待未来更高的温度
            stk.push(i);
        }

        return res;
    }
};
```

题目保证 n >= 1，预先压入下标 0 的写法正确。也可以删去 `stk.push(0)`，让 for 从 i = 0 开始，其余逻辑不变。

## 一轮到底做什么

1. 如果今天比栈顶那天热，栈顶那天就找到了答案，记录距离并弹出。
2. 继续检查新的栈顶，一天可能回答之前多个日期，所以使用 while。
3. 栈空或栈顶温度 >= 今天时停止，然后把今天入栈。

为什么找到的是“第一个”更高温度？日期按从左到右的顺序扫描；某个日期仍留在栈里，说明此前尚未遇到更高温度。遇到更高温度时，上面更低或相等的待处理温度会先被弹出，随后就能处理它。

## 示例模拟

输入 `[73,74,75,71,69,72,76,73]`，栈写为 `下标:温度`，从左到右为栈底到栈顶。

| 今天 | 本轮回答的日期 | 入栈后 |
|---|---|---|
| 0:73 | 无 | `[0:73]` |
| 1:74 | res[0] = 1 | `[1:74]` |
| 2:75 | res[1] = 1 | `[2:75]` |
| 3:71 | 无 | `[2:75, 3:71]` |
| 4:69 | 无 | `[2:75, 3:71, 4:69]` |
| 5:72 | res[4] = 1，res[3] = 2 | `[2:75, 5:72]` |
| 6:76 | res[5] = 1，res[2] = 4 | `[6:76]` |
| 7:73 | 无 | `[6:76, 7:73]` |

最终留下的 6、7 都没有未来更高温度，答案维持初始的 0，得到 `[1,1,4,2,1,1,0,0]`。

## 本轮易错点

- `while (stk.empty())` 写反：预先压入 0 后栈非空，循环始终不进入，答案全为 0。应先检查 `!stk.empty()` 再访问 top；`&&` 短路保证空栈不会读取栈顶。
- 只用 if：一次只能处理一个日期，漏掉同一天可以回答的其他日期。
- 找到答案后没有 pop：已经解决的日期会阻挡下面的日期，也可能被覆盖答案。
- 只在某个分支中 push：若弹栈后变空，今天就会遗漏。统一在 while 后入栈。
- 比较必须是 `>`：相同温度不能解答“更高温度”，例如 `[70,70,71]` 应返回 `[2,1,0]`。
- 函数末尾需要 `return res;`。

## 边界与复杂度

- `[73]`：返回 `[0]`。
- `[73,73]`：相等不弹栈，返回 `[0,0]`。
- `[75,74,73]`：所有日期留在栈中，返回 `[0,0,0]`。
- `[30,40,50,60]`：返回 `[1,1,1,0]`。

每个下标只入栈一次，最多出栈一次，所有 while 的总弹栈次数不超过 n，因此时间 O(n)。栈最坏保存 n 个下标，辅助空间 O(n)，输出数组也占 O(n)。
