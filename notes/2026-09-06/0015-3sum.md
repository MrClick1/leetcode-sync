# 15. 三数之和

状态：✅ 已解决（2026-09-06，排序 + 双指针解法通过 LeetCode）

## 题目要求

给定整数数组 `nums`，返回所有和为 `0` 且不重复的三元组。三元组中的三个下标必须互不相同，结果顺序任意。

## 解法：排序 + 固定一个数 + 双指针

先将数组排序。固定第一个数 `nums[i]` 后，在右侧区间 `[i + 1, n - 1]` 使用左右指针寻找另外两个数：

```text
nums[i] + nums[left] + nums[right]
```

排序后：

- 和小于 `0`：需要更大的值，`left++`
- 和大于 `0`：需要更小的值，`right--`
- 和等于 `0`：记录三元组，并同时移动两个指针

```cpp
class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        int n = static_cast<int>(nums.size());
        vector<vector<int>> res;

        for (int i = 0; i < n - 2; ++i) {
            if (i > 0 && nums[i] == nums[i - 1]) {
                continue;
            }

            if (nums[i] > 0) {
                break;
            }

            int left = i + 1;
            int right = n - 1;

            while (left < right) {
                long long sum =
                    static_cast<long long>(nums[i]) +
                    nums[left] + nums[right];

                if (sum < 0) {
                    ++left;
                } else if (sum > 0) {
                    --right;
                } else {
                    res.push_back({nums[i], nums[left], nums[right]});
                    ++left;
                    --right;

                    while (left < right && nums[left] == nums[left - 1]) {
                        ++left;
                    }
                    while (left < right && nums[right] == nums[right + 1]) {
                        --right;
                    }
                }
            }
        }

        return res;
    }
};
```

用户最终提交的版本在 `sum < 0` 和 `sum > 0` 分支中也提前跳过了重复值，这不会影响正确性；标准模板通常只在找到答案后跳过重复值，结构更简洁。

## 去重规则

需要处理两类重复：

### 固定值去重

```cpp
if (i > 0 && nums[i] == nums[i - 1]) {
    continue;
}
```

例如排序后有多个 `-1`，只让第一个 `-1` 作为固定值，否则会重复搜索相同的三元组。

### 找到答案后去重

找到一个答案后，先移动指针，再跳过与刚才使用的值相同的元素：

```cpp
++left;
--right;

while (left < right && nums[left] == nums[left - 1]) ++left;
while (left < right && nums[right] == nums[right + 1]) --right;
```

只在和为 `0` 时需要这样去重。和小于或大于 `0` 时，指针单向移动即可，重复值不会直接产生重复结果。

## 减枝

排序后，如果固定值已经大于 `0`：

```cpp
if (nums[i] > 0) break;
```

因为后面的数只会更大，不可能再组成和为 `0` 的三元组。

## 本轮越界问题

最初的重复跳过代码直接访问了相邻位置：

```cpp
while (nums[left] == nums[left + 1]) ...
while (nums[right] == nums[right - 1]) ...
```

当 `left` 或 `right` 移动到边界时，`left + 1` 可能等于 `n`，或者 `right - 1` 可能小于 `0`，从而触发 `vector` 越界。修复时必须加入边界条件，例如：

```cpp
while (left < right && nums[left] == nums[left + 1]) ++left;
while (left < right && nums[right] == nums[right - 1]) --right;
```

更推荐先移动指针，再和前一个位置或后一个位置比较，避免直接访问不确定的邻居。

## 复杂度

- 排序：`O(n log n)`。
- 外层固定一个数，内层双指针：`O(n²)`。
- 总时间复杂度：`O(n²)`。
- 除结果外的额外空间复杂度：`O(1)`（不计排序实现可能使用的栈空间）。

## C++ 注意点

- `res.push_back({a, b, c})` 会构造一个临时 `vector<int>`，因为 `res` 的元素类型是 `vector<int>`。
- `long long sum = nums[i] + nums[left] + nums[right]` 不一定能避免中间计算溢出；应让至少一个操作数先转换为 `long long`。
- `for (int i = 0; i <= n - 3; ++i)` 在本题约束下可行，`i < n - 2` 更直观。
