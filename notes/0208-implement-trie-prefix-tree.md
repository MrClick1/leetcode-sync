# 208. 实现 Trie（前缀树） —— 复盘笔记

状态：✅ 已解决

## 遇到的问题

1. 不理解节点结构：每个节点代表一个"前缀"，`children[26]` 对应 a–z，`isEnd` 标记完整词
2. 不理解 `TrieNode* children[26] = {nullptr};` 的初始化：初始化列表没写满时，**剩余元素自动补零值**（指针就是 nullptr）
3. 不知道 `root` 从哪来：它是类的私有成员，构造函数里 `new` 出来；辅助函数直接用即可

## 解题要点

- 节点 = 一个前缀的"代言人"；`root` = 空前缀
- **公共前缀只建一次**，多个单词共享路径（如 "app" 和 "apple" 共享 a→p→p）
- `insert`：沿字符走，缺哪个字符就 `new` 哪个节点挂上去，最后 `isEnd = true`
- `search`：沿字符走，中途断链返回 false，最后**看 `isEnd`**（必须是完整单词）
- `startsWith`：沿字符走，能走通就 true，**不看 `isEnd`**
- 三个方法都是同一个"沿字符往下走"的模式，差异只在最后一步
- 简化：`insert` 一遍遍历即可（边建边走），不需要先 `findNode` 再走第二遍
- 小坑：`TrieNode* children[26] = {nullptr}` 只写一个元素，剩余 25 个自动为 nullptr
