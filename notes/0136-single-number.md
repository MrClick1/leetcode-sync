# 136. 只出现一次的数字 —— 复盘笔记

状态：✅ 已解决

## 遇到的问题

1. 第一版用 `unordered_map` 计数——正确但空间 O(n)，不满足"常量额外空间"的要求
2. 对异或不熟：不理解 `a ^ a = 0`、交换律/结合律的来源（异或 = 每位独立的模 2 加法 = 数 1 的奇偶）

## 解题要点

- 位运算 **XOR**：`a ^ a = 0`、`a ^ 0 = a`、交换律 + 结合律
- 全部元素依次异或：成对的抵消为 0，剩下的就是只出现一次的数
- O(n) 时间 + O(1) 空间，恰好命中题目约束
- 为什么其他思路不行：排序 O(n log n) 时间；哈希表 O(n) 空间
- 代码：`int result = 0; for (int x : nums) result ^= x;`
