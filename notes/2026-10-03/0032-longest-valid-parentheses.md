## 用户最新整理版

用户在官解对照后修改为只处理右括号，并用 k 表示候选匹配左括号的位置。保留原来的 n<=1 特判、dp[1] 初始化及从 i=2 开始的循环。此版静态核对逻辑正确，与此前已通过版的递推等价；尚未收到用户对本整理版再次力扣提交通过的明确反馈，本轮未新增编译运行测试。

```cpp
class Solution {
public:
    int longestValidParentheses(string s) {
        int n = (int)s.size();
        int res = 0;

        if (n <= 1) return 0;

        vector<int> dp(n, 0);      // 以下标为 i 结尾的字符串的最长有效括号的长度

        if (s[1] == ')' && s[0] == '(') dp[1] = 2;
        res = max(res, dp[1]);

        for (int i = 2; i < n; ++i) {
            if (s[i] == ')') {
                if (s[i-1] == '(') {
                    dp[i] = dp[i-2] + 2;
                } else {
                    int k = i - dp[i-1] - 1;
                    if (k >= 0 && s[k] == '(') {
                        // (())
                        dp[i] = dp[i-1] + 2;

                        if (k > 0) {
                            dp[i] += dp[k-1];
                        }
                    }
                }
            }

            res = max(res, dp[i]);
        }

        return res;
    }
};
```

当前左括号分支不再写无效的 dp[i]==0，零初始化已经满足状态含义。k>=0 检查后才能读取 s[k]；k>0 检查后才能读取 dp[k-1]。循环从2开始使 dp[i-2] 始终合法。res 在分支外更新也正确，左括号状态为0不会影响最大值。注释“(())”只是一个例子，实际处理所有 A(B) 结构，B 可以更长或含多组括号，A 也可以为空；可选改为“匹配 k 和 i，包住中间有效段，再接前段”。无需为了贴近官解而再改写三元表达式。

## 状态与两种转移

dp[i] 表示必须以 s[i] 结尾的最长连续有效括号子串长度，res 表示所有已处理位置中的最长长度。有效括号必须以右括号结尾，当前字符为左括号时 dp[i]=0。例 ()( 的 dp 为 [0,2,0]，答案取历史最大值 2。

当前为右括号且前一个字符为左括号，形成新的一对 ()，再连接紧邻前方的有效段：dp[i]=dp[i-2]+2。用户单独初始化 dp[1]，循环从 i=2 开始，所以 i-2 始终合法。

当前为右括号且前一个字符也为右括号，先跳过前一位置结尾的有效段 B，其长度为 dp[i-1]。B 的前一个字符下标为 k=i-dp[i-1]-1。若 k>=0 且 s[k]=='('，就能用这对括号把 B 包起来，并连接其前方的有效段 A：

```text
A       ( B )
结束于   k   i
k-1

dp[i] = dp[k-1] + dp[i-1] + 2
```

k=0 时没有 A，前段长度按零处理。只有 k>0 时才能访问 dp[k-1]。可以把重复下标表达式命名为 k，使含义更清楚：

```cpp
int k = i - dp[i - 1] - 1;
if (k >= 0 && s[k] == '(') {
    dp[i] = dp[i - 1] + 2;
    if (k > 0) {
        dp[i] += dp[k - 1];
    }
}
```

这个片段与用户通过版等价，不需要改变原来的 dp[1] 初始化或循环范围。

## 与官解的区别及写法记忆

本轮比较依据为用户贴出的完整[力扣官解代码](https://leetcode.cn/problems/longest-valid-parentheses/solutions/314683/zui-chang-you-xiao-gua-hao-by-leetcode-solution/)，未另行访问网页。两者递推关系相同，差别在初始化、边界检查和代码组织，不是不同的算法，均为 O(n) 时间、O(n) 额外空间。

| 对照点 | 用户通过版 | 官解 |
|---|---|---|
| 开始位置 | n<=1 提前返回，单独算 dp[1]，从 i=2 遍历 | 从 i=1 遍历；读取 dp[i-2] 前用三元运算处理 i=1 |
| 当前字符 | 左括号分支保留零，else 处理右括号 | 只在 s[i]==')' 时计算，左括号沿用初始化的零 |
| 匹配左括号 | i-dp[i-1]-1>=0 | i-dp[i-1]>0，两者等价 |
| 连接前段 | k>0 时另加 dp[k-1] | 三元表达式将前段长度与内层长度、加2写在一起 |
| 更新历史答案 | 每轮都更新 res | 只在右括号分支更新 maxans；左括号状态为零，无需更新 |

令 k=i-dp[i-1]-1，则官解两个条件的对应关系为：

```text
i-dp[i-1]>0   ⇔ k>=0：匹配的左括号下标合法
i-dp[i-1]>=2  ⇔ k>0 ：左括号之前还有位置，才能读取 dp[k-1]
```

三元运算 condition ? value1 : value2 只求值被选中的分支。例如 i>=2 ? dp[i-2] : 0 在 i=1 时只取0，不会读取 dp[-1]。不能不加边界检查地直接把缺失的前段当成数组中的一个零元素。

记忆时先画结构，再写下标，不背官解中很长的表达式：

```text
当前 s[i] 是 '('：dp[i]=0，不可能有以它结尾的有效串。

当前 s[i] 是 ')'，前一个是 '('：
    A ()
    A 结束于 i-2；dp[i]=前段A长度+2。

当前 s[i] 是 ')'，前一个是 ')'：
    A ( B )
      k   i
    B 结束于 i-1，长度为 dp[i-1]。
    k=i-dp[i-1]-1，先确认 k>=0 且 s[k]=='('。
    dp[i]=B长度+2，再加结束于 k-1 的前段A长度（存在才读取）。
```

这里不是任意挑一个前面的 dp 去取最大，而是只连接紧邻的有效段，保证子串连续。所有位置的 dp 算完后，用 res 保存其中最大值。用 () 检查第一种转移与 i=1 边界，用 (()) 检查跳过内层，用 ()(()) 检查接前段，用 ()) 检查 k=-1，用 ()( 检查不能只返回末项。

下面是沿用官解遍历范围、保留用户分步相加风格的学习参考。它不替换上方用户通过版，也不是用户新提交通过的版本：

```cpp
class Solution {
public:
    int longestValidParentheses(string s) {
        int n = (int)s.size();
        vector<int> dp(n, 0);
        int res = 0;

        for (int i = 1; i < n; ++i) {
            if (s[i] == '(') continue;

            if (s[i - 1] == '(') {
                dp[i] = 2;
                if (i >= 2) dp[i] += dp[i - 2];
            } else {
                int k = i - dp[i - 1] - 1;
                if (k >= 0 && s[k] == '(') {
                    dp[i] = dp[i - 1] + 2;
                    if (k > 0) dp[i] += dp[k - 1];
                }
            }

            res = max(res, dp[i]);
        }
        return res;
    }
};
```

## 前方有多组括号为何不漏

dp[k-1] 保存以 k-1 结尾的整段最长有效括号，可能包含多组相邻或嵌套的括号，不只是最近的一对。此前的转移已经把能连续连接的部分累积进去。

例如 ()()(())：

```text
下标：0 1 2 3 4 5 6 7
字符：( ) ( ) ( ( ) )
      └─────┘ └─────┘
        A       (B)
```

处理前两组 () 时，dp[1]=2、dp[3]=dp[1]+2=4。处理最后的 i=7 时，中间的 B 是下标 [5,6] 的 ()，dp[6]=2，所以 k=7-2-1=4。前段 dp[k-1]=dp[3]=4，已经包含前面两组 ()。于是 dp[7]=2+2+4=8，一次相加即可全部连接。

前面再多一组 ()，其长度同样会提前累积到 dp[k-1]。如果还能往前连续延长，dp[k-1] 本身作为最长状态就已包含它；不需要在本轮再往前逐组查找。只能接以 k-1 结尾的那一段，不能使用 res 代替它，否则可能越过无法匹配的括号而破坏连续性。

## 复习与验证范围

先定义必须以 i 结尾的 dp，再按当前字符是否为右括号分支。直接组成 () 时接 dp[i-2]；跳过中间段时计算 k、检查匹配、再接 dp[k-1]。最后保留所有位置的历史最大值。

用 ()) 检查 k 的负下标，用 ()( 检查答案不是末项，用 ()()(()) 检查前段已累积多组括号。时间 O(n)，额外空间 O(n)。用户反馈力扣通过，本轮静态审查与手工状态推演正确；没有新增本地编译或运行测试，也没有复用旧栈解法的测试结果来声称 DP 版通过本地测试。

## 当前转向栈解法练习

已有[下标栈笔记](../2026-09-04/0032-longest-valid-parentheses.md)可复用，但用户这次重新练习尚未给出新的栈代码，不标为本轮新提交通过。以下是实现前的思路提示，不再继续 DP 官解对照：

- 保存下标而非括号字符，因为要计算连续长度，不是统计所有匹配对数。
- 栈底先放 -1，表示字符串开始前的虚拟边界，不读取 s[-1]。
- 遇到左括号，将当前下标 i 入栈。
- 遇到右括号，先弹出一个下标；若栈空，当前右括号无法匹配，将 i 入栈作为新的不可跨越边界；若非空，以当前 i 结尾的有效长度为 i-stk.top()。
- 每个右括号仅弹出一次，不用 while 一直弹空。每轮结束时栈非空，故下次右括号的首次 pop 安全。

剩余栈顶可能是未匹配的左括号，也可能是栈底边界；它都是当前连续有效后缀之前不能包含的位置，因此从其后一个位置开始，长度为 i-stk.top()，不再加1。

手工例 ()()：下标1的右括号匹配后剩余栈顶为-1，长度1-(-1)=2；下标3的右括号匹配后仍剩余-1，长度3-(-1)=4。例 (()：下标2匹配下标1后仍有未匹配左括号0，长度2-0=2，不能跨过0。时间 O(n)、最坏空间 O(n)；本轮只静态说明与手工推演，没有新增本地编译运行，也不把旧栈笔记的测试记录当成本轮验证。
