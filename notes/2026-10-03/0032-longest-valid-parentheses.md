## 用户最新整理版

用户在官解对照后修改为只处理右括号，并用 k 表示候选匹配左括号的位置。保留原来的 n<=1 特判、dp[1] 初始化及从 i=2 开始的循环。此版静态核对逻辑正确，与此前已通过版的递推等价；尚未收到用户对本整理版再次力扣提交通过的明确反馈，本轮未新增编译运行测试。

```cpp
class Solution {
public:
    int longestValidParentheses(string s) {
        int n = (int)s.size();
        int res = 0;

        if (n <= 1) return 0;

        vector<int> dp(n, 0);      // 以下标为 i 结尾的字符串的最长有效括号的长度

        if (s[1] == ')' && s[0] == '(') dp[1] = 2;
        res = max(res, dp[1]);

        for (int i = 2; i < n; ++i) {
            if (s[i] == ')') {
                if (s[i-1] == '(') {
                    dp[i] = dp[i-2] + 2;
                } else {
                    int k = i - dp[i-1] - 1;
                    if (k >= 0 && s[k] == '(') {
                        // (())
                        dp[i] = dp[i-1] + 2;

                        if (k > 0) {
                            dp[i] += dp[k-1];
                        }
                    }
                }
            }

            res = max(res, dp[i]);
        }

        return res;
    }
};
```

当前左括号分支不再写无效的 dp[i]==0，零初始化已经满足状态含义。k>=0 检查后才能读取 s[k]；k>0 检查后才能读取 dp[k-1]。循环从2开始使 dp[i-2] 始终合法。res 在分支外更新也正确，左括号状态为0不会影响最大值。注释“(())”只是一个例子，实际处理所有 A(B) 结构，B 可以更长或含多组括号，A 也可以为空；可选改为“匹配 k 和 i，包住中间有效段，再接前段”。无需为了贴近官解而再改写三元表达式。

## 状态与两种转移

dp[i] 表示必须以 s[i] 结尾的最长连续有效括号子串长度，res 表示所有已处理位置中的最长长度。有效括号必须以右括号结尾，当前字符为左括号时 dp[i]=0。例 ()( 的 dp 为 [0,2,0]，答案取历史最大值 2。

当前为右括号且前一个字符为左括号，形成新的一对 ()，再连接紧邻前方的有效段：dp[i]=dp[i-2]+2。用户单独初始化 dp[1]，循环从 i=2 开始，所以 i-2 始终合法。

当前为右括号且前一个字符也为右括号，先跳过前一位置结尾的有效段 B，其长度为 dp[i-1]。B 的前一个字符下标为 k=i-dp[i-1]-1。若 k>=0 且 s[k]=='('，就能用这对括号把 B 包起来，并连接其前方的有效段 A：

```text
A       ( B )
结束于   k   i
k-1

dp[i] = dp[k-1] + dp[i-1] + 2
```

k=0 时没有 A，前段长度按零处理。只有 k>0 时才能访问 dp[k-1]。可以把重复下标表达式命名为 k，使含义更清楚：

```cpp
int k = i - dp[i - 1] - 1;
if (k >= 0 && s[k] == '(') {
    dp[i] = dp[i - 1] + 2;
    if (k > 0) {
        dp[i] += dp[k - 1];
    }
}
```

这个片段与用户通过版等价，不需要改变原来的 dp[1] 初始化或循环范围。

```cpp
class Solution {
public:
    int longestValidParentheses(string s) {
        int n = (int)s.size();
        vector<int> dp(n, 0);
        int res = 0;

        for (int i = 1; i < n; ++i) {
            if (s[i] == '(') continue;

            if (s[i - 1] == '(') {
                dp[i] = 2;
                if (i >= 2) dp[i] += dp[i - 2];
            } else {
                int k = i - dp[i - 1] - 1;
                if (k >= 0 && s[k] == '(') {
                    dp[i] = dp[i - 1] + 2;
                    if (k > 0) dp[i] += dp[k - 1];
                }
            }

            res = max(res, dp[i]);
        }
        return res;
    }
};
```

## 前方有多组括号为何不漏

dp[k-1] 保存以 k-1 结尾的整段最长有效括号，可能包含多组相邻或嵌套的括号，不只是最近的一对。此前的转移已经把能连续连接的部分累积进去。

例如 ()()(())：

```text
下标：0 1 2 3 4 5 6 7
字符：( ) ( ) ( ( ) )
      └─────┘ └─────┘
        A       (B)
```

处理前两组 () 时，dp[1]=2、dp[3]=dp[1]+2=4。处理最后的 i=7 时，中间的 B 是下标 [5,6] 的 ()，dp[6]=2，所以 k=7-2-1=4。前段 dp[k-1]=dp[3]=4，已经包含前面两组 ()。于是 dp[7]=2+2+4=8，一次相加即可全部连接。

前面再多一组 ()，其长度同样会提前累积到 dp[k-1]。如果还能往前连续延长，dp[k-1] 本身作为最长状态就已包含它；不需要在本轮再往前逐组查找。只能接以 k-1 结尾的那一段，不能使用 res 代替它，否则可能越过无法匹配的括号而破坏连续性。

## 本轮栈解法已通过

用户本轮先漏掉了栈空时的边界更新，补齐后已明确反馈力扣通过。以下是最终代码的思路，仍保留[原下标栈笔记](../2026-09-04/0032-longest-valid-parentheses.md)作为历史参考；此后用户已主动开始学习下方的双向计数方法。

- 保存下标而非括号字符，因为要计算连续长度，不是统计所有匹配对数。
- 栈底先放 -1，表示字符串开始前的虚拟边界，不读取 s[-1]。
- 遇到左括号，将当前下标 i 入栈。
- 遇到右括号，先弹出一个下标；若栈空，当前右括号无法匹配，将 i 入栈作为新的不可跨越边界；若非空，以当前 i 结尾的有效长度为 i-stk.top()。
- 每个右括号仅弹出一次，不用 while 一直弹空。每轮结束时栈非空，故下次右括号的首次 pop 安全。

剩余栈顶可能是未匹配的左括号，也可能是栈底边界；它都是当前连续有效后缀之前不能包含的位置，因此从其后一个位置开始，长度为 i-stk.top()，不再加1。

手工例 ()()：下标1的右括号匹配后剩余栈顶为-1，长度1-(-1)=2；下标3的右括号匹配后仍剩余-1，长度3-(-1)=4。例 (()：下标2匹配下标1后仍有未匹配左括号0，长度2-0=2，不能跨过0。时间 O(n)、最坏空间 O(n)；本轮只静态说明与手工推演，没有新增本地编译运行，也不把旧栈笔记的测试记录当成本轮验证。

### 用户本轮通过代码

```cpp
class Solution {
public:
    int longestValidParentheses(string s) {
        int n = (int)s.size();
        stack<int> stk;
        stk.push(-1);

        int res = 0;

        for (int i = 0; i < n; ++i) {
            if (s[i] == '(') {
                stk.push(i);
            } else {
                stk.pop();

                if (stk.empty()) {
                    stk.push(i);
                } else {
                    res = max(res, i - stk.top());
                }
            }
        }

        return res;
    }
};
```

### 本轮空栈错误及修正

首版在 pop 后只检查非空再计算长度，漏写栈空时的 stk.push(i)。输入 "))" 时，初始 [-1] 被第一个右括号弹空；第二个右括号对空栈 pop，产生未定义行为。后面的非空判断只保护 top，无法补救此前非法的 pop。错误报在 stl_deque.h，是因为 stack<int> 默认用 deque<int> 存储，非法栈操作可能在底层表现为引用绑定到未对齐地址；应检查容器操作前提，无需改变 int 的对齐方式。

缺边界也会影响答案：输入 ")()" 时，首版依次经历 [-1]→[]→[1]→[]，始终没有更新 res，错误返回0。修正后下标0作为新边界，最后匹配后栈顶是0，长度为2-0=2。stk.push(i) 同时恢复下一轮 pop 的安全前提，并记录后续有效子串不能跨越的位置。

最终版每轮开始、结束时栈都非空。栈底是 -1 或最近一个未匹配右括号的下标，以上是未匹配左括号下标。匹配后剩余栈顶 b 是当前有效后缀前的边界，因此有效范围为 [b+1,i]，长度 i-(b+1)+1=i-b。每个下标最多入栈、出栈各一次，所以时间 O(n)，最坏空间 O(n)。用户已反馈本轮力扣通过；本轮独立静态复核与手工推演正确，没有新增本地编译运行，不重复宣称9月栈实现的测试结果。

## 官解方法三：双向计数（用户已通过）

本节依据用户贴出的完整官解说明与代码，未另行访问网页。left/right 分别是当前计数区间里左右括号的数量，不是左右指针。计数区间从本趟起点或最近一次重置后的字符开始；重置不修改字符串，只放弃从原起点继续拼接，已经发现的答案仍由 maxlength 保存。

### 正向扫描

遇到 '(' 增加 left，遇到 ')' 增加 right：

- left==right：当前段有效，更新 maxlength=max(maxlength,2*right)。
- right>left：出现无法匹配的右括号，left=right=0，从下一位重新计数。
- left>right：暂时有多余左括号，保留计数，等待后面的右括号。

不能仅凭总数相等断定有效，例如 ")(" 数量相等却无效。正向遇到 right>left 立即重置，保证当前候选段的任意前缀都有 left>=right；再结合整段 left==right，就能确认括号顺序也正确。右括号需要前面的左括号，后面新来的左括号无法补救已经失配的右括号，因此重置点不能被后续有效子串跨越。

例 ")()())"，表中为读入当前字符后、执行重置前的计数：

| i | 字符 | left | right | 动作 |
|---|---|---|---|---|
| 0 | ')' | 0 | 1 | 重置为0、0 |
| 1 | '(' | 1 | 0 | 等待 |
| 2 | ')' | 1 | 1 | 当前长度2，答案2 |
| 3 | '(' | 2 | 1 | 等待 |
| 4 | ')' | 2 | 2 | 当前长度4，答案4 |
| 5 | ')' | 2 | 3 | 重置，答案仍为4 |

相等时只更新答案，不清零计数；这样可以把相邻的 "()()" 连起来。只有失配时才重新划定起点。

### 为什么要反向扫描

正向遇到 "(()"，计数依次是(1,0)、(2,0)、(2,1)，一直没有相等，漏掉后面的 "()"。不能一看到 left>right 就正向重置，因为正常 "(())" 也会先积累左括号。

反向仍然在原字符串上读取字符，'(' 仍增加 left、')' 仍增加 right；只是 i 从 n-1 走到0。此时先积累右括号，等待左侧出现左括号，失配条件反过来：left>right 时重置。left==right 时更新2*left，right>left 时继续等待。

反向扫描 "(()"：

| i | 字符 | left | right | 动作 |
|---|---|---|---|---|
| 2 | ')' | 0 | 1 | 等待左侧的 '(' |
| 1 | '(' | 1 | 1 | 原串区间[1,2]是"()"，答案2 |
| 0 | '(' | 2 | 1 | 多余左括号，重置 |

反向失配重置保证当前候选段的任意后缀都有 right>=left；计数相等时整段有效。正向能处理多余右括号形成的断点，反向能处理多余左括号形成的断点，两趟取同一个最大值，覆盖最长有效段。无需声称每一趟都会找到所有以当前位置结尾的有效子串，也不需要枚举每个有效子串。

### 代码与记忆检查

| 遍历方向 | 允许暂时较多的括号 | 必须重置的条件 | 更新答案的条件 |
|---|---|---|---|
| 从左到右 | '('，等待右侧的 ')' | right>left | left==right |
| 从右到左 | ')'，等待左侧的 '(' | left>right | left==right |

两趟之间只执行 left=right=0，保留 maxlength；相等时2*left和2*right相同。无需反转字符串或交换括号字符，也无需分配栈或数组。逆向起点按官解写成 (int)s.size()-1，可在空串时得到-1并直接跳过循环。扫描两趟是2n次，时间 O(n)，额外空间 O(1)。

### 用户通过代码及官解对照

```cpp
class Solution {
public:
    int longestValidParentheses(string s) {
        int n = (int)s.size();

        int left = 0;
        int right = 0;
        int res = 0;

        // 从左到右
        for (int i = 0; i < n; ++i) {
            char c = s[i];
            if (c == '(') {
                ++left;
            } else {
                ++right;
            }

            if (left == right) {
                res = max(res, left + right);
            } else if (left < right) {
                left = 0;
                right = 0;
            }
        }

        // 从右到左
        left = 0;
        right = 0;
        for (int i = n-1; i >= 0; --i) {
            char c = s[i];
            if (c == '(') {
                ++left;
            } else {
                ++right;
            }

            if (left == right) {
                res = max(res, left + right);
            } else if (left > right) {
                left = 0;
                right = 0;
            }
        }

        return res;
    }
};
```
