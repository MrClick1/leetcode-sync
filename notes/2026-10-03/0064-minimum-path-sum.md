# 64. 最小路径和

2026-10-03 用户修正两次首行初始化错误后，明确反馈一维滚动数组解法力扣通过。本题重点是到达当前格子的最小路径和，以及同一数组中上方旧状态和左方新状态的区别。

## 用户通过代码

```cpp
class Solution {
public:
    int minPathSum(vector<vector<int>>& grid) {
        int m = (int)grid.size();
        int n = (int)grid[0].size();

        vector<int> dp(n);
        dp[0] = grid[0][0];

        // 初始化
        for (int j = 1; j < n; ++j) {
            dp[j] = dp[j-1] + grid[0][j];
        }

        // 递推
        for (int i = 1; i < m; ++i) {
            for (int j = 0; j < n; ++j) {
                if (j > 0) {
                    dp[j] = min(dp[j], dp[j-1]) + grid[i][j];
                } else if (j == 0) {
                    dp[j] = dp[j] + grid[i][j];
                }
            }
        }

        return dp[n-1];
    }
};
```

## 状态与递推

若先用二维状态理解，f[i][j] 表示从左上角到达格子(i,j)的最小路径和，包含起点与当前格子的值。只允许向右或向下，因此到达当前格子的最后一步只能来自上方(i-1,j)或左方(i,j-1)。两者都存在时：

```cpp
f[i][j] = min(f[i-1][j], f[i][j-1]) + grid[i][j];
```

用户已经直接写成一维滚动数组。处理第i行、从左往右更新第j列之前：

| 表达式 | 此刻保存的含义 |
|---|---|
| dp[j] | 上一行的结果，即上方格子的最小路径和 |
| dp[j-1] | 当前行已经更新的结果，即左方格子的最小路径和 |
| grid[i][j] | 当前格子本身的值 |

于是原地更新 dp[j]=min(dp[j],dp[j-1])+grid[i][j] 即可。这里需要从左往右，才能让左方状态属于当前行；不能机械套用0/1背包的倒序规则。每行结束后dp保存这一整行的结果，最终返回右下角对应的dp[n-1]，不需要对所有格子的状态另取最小值。

## 首行、首列的边界

- 起点：dp[0]=grid[0][0]。
- 首行只能从左边来：dp[j]=dp[j-1]+grid[0][j]。
- 首列只能从上面来：dp[0]+=grid[i][0]。

到当前格子的路径和，等于此前累计路径和加当前格子的值。前一个格子的值已经包含在此前累计值中，不能再加一次。

用户else if(j==0)可以简化为else，因为循环保证j>=0；当前写法正确，没有必要为此改动已通过代码。grid只被读取，不会被本算法修改。

## 两次初始化错误

首版写成 dp[j]+=grid[0][j-1]。vector<int> dp(n) 初始化为零，除dp[0]外，这实际上只保存前一个格子的值，没有累计，也没有加当前格子。示例首行[1,3,1]会错误得到[1,1,3]，正确应为[1,4,5]；完整示例因此错误得到5而非7。

第二版写成 dp[j]=dp[j-1]+grid[0][j-1]，虽然已经使用累计值，却仍加了前一个格子的值。对于首行[1,2,3]，得到[1,2,4]而非[1,3,6]。处理下一行[4,5,6]后：

| 阶段 | 第二版错误状态 | 最终正确状态 |
|---|---|---|
| 第一行 | [1,2,4] | [1,3,6] |
| 第二行 | [5,7,10] | [5,8,12] |

最终只需使用 dp[j-1]+grid[0][j]，后面两种递推分支原本就是正确的；不再把历史初始化错误当作当前问题。

## 复杂度与复习

时间O(mn)，额外空间O(n)，其中n是列数。单行时完成首行初始化后直接返回；单列时逐行累加dp[0]；单格直接返回起点。题目保证网格非空，无需额外增加空网格分支。

路径必经m+n-1个格子，按本题上限，路径和最多为(200+200-1)*200=79,800，int足够。
