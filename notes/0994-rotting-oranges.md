# 994. 腐烂的橘子 —— 复盘笔记

状态：✅ 已解决（多源 BFS，O(mn) 时间）

## 遇到的问题

1. 一开始想"找孤立橘子群 + 每群从单个腐烂源 BFS + 取最大值"——但一个群可能**有多个腐烂源**，会算错
2. `minutes - 1` 的返回写法依赖"队列至少跑一轮"：全空网格 `[[0]]` 时队列为空，`0 - 1 = -1` 报错
3. **两个修复混用**：加了 `rotten` 标志后又保留 `minutes - 1`，结果每道题都少一分钟（示例 1 输出 3）
4. 测试程序输出中文在 Windows 终端乱码（GBK 代码页）→ 输出改成英文

## 解题要点

- **多源 BFS**：把所有初始腐烂橘子（2）同时入队，每个新鲜橘子烂掉的时间 = 到最近腐烂源的距离，一次 BFS 全算出来
- **分层计数**：`size = q.size()` 记录当前这一分钟的扩散范围，处理完一整层 = 1 分钟
- **只在真的烂了橘子时才计时**（`rotted` 标志），结尾直接返回 `minutes`，不需要 `-1`
- **改值代替 visited**：新鲜橘子烂掉时 `grid[r][c] = 2`，既是标记又是新腐烂源，省 visited 数组
- 最后检查 `fresh`：还有新鲜橘子 → `-1`（被 0 隔开永远烂不到）
- 与 200 的关系：200 只数连通块数量；994 多了"多源"和"计时"两个维度

## 延伸练习

- [ ] 不修改原网格的版本：用 `dist` 二维数组记录每个格子的腐烂时间，代替原地改值
- [ ] 变体题：要求输出每个新鲜橘子烂掉的具体时间矩阵（多源最短距离）

## 复杂度

- 时间：O(mn)
- 空间：O(mn)（队列最多存 m×n 个格子）
