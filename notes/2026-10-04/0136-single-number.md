# 136. 只出现一次的数字（二刷）

## 用户通过代码

```cpp
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        int n = (int)nums.size();
        int res = 0;

        for (int i = 0; i < n; ++i) {
            res ^= nums[i];
        }

        return res;
    }
};
```

## 为什么全部异或能找到答案

题目保证恰好一个数字出现一次，其余数字各出现两次。按位异或的关键性质为：

```text
a ^ a = 0                 // 相同数字抵消
a ^ 0 = a                 // 与零异或不改变数字
a ^ b = b ^ a             // 交换律
(a ^ b) ^ c = a ^ (b ^ c) // 结合律
```

异或逐位计算：对应位相同得 0，不同得 1。任何数与自身异或，每一位都变成 0；与 0 异或，每一位仍保持原值。

交换律、结合律允许在证明中把相同数字配成对，不要求它们在原数组中相邻，也不需要真的排序或改变数组。例如：

```text
4 ^ 1 ^ 2 ^ 1 ^ 2
= 4 ^ (1 ^ 1) ^ (2 ^ 2)
= 4 ^ 0 ^ 0
= 4
```

## res 的含义与一次扫描

循环开始前 res=0；处理下标 i 后，res 等于 nums[0] 到 nums[i] 的累计异或。它不一定已经是最终答案，也不是当前最大的数字。

以 nums=[4,1,2,1,2] 为例：

| 处理的数字 | 累计计算 | res |
|---|---|---:|
| 初始 | 0 | 0 |
| 4 | 0 ^ 4 | 4 |
| 1 | 4 ^ 1 | 5 |
| 2 | 5 ^ 2 | 7 |
| 1 | 7 ^ 1 | 6 |
| 2 | 6 ^ 2 | 4 |

最后所有数字都已处理，出现两次的数抵消，因此返回 res。

## 语法与边界

- res ^= nums[i] 在这里等价于 res = res ^ nums[i]；^ 是按位异或，不是乘方。
- 初始值取 0，是因为 0 ^ x = x，不会额外引入一个数字。
- 单元素数组 [x] 返回 x；只出现一次的数可以是 0，也可以是负数。
- 成对的负数同样抵消，不需要为负数额外写分支。
- 不修改 nums，没有辅助哈希表或额外数组。
- 用户的下标循环无需修改；for(int x : nums) res ^= x 也等价，但并不是新的算法优化。

更多语法见 [C++ 语法笔记](../01-cpp语法知识文档.md)中的“3.15 幂运算与平方 / ^ 是按位异或”。
