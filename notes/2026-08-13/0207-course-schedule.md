# 207. 课程表 —— 复盘笔记

状态：✅ 已解决（拓扑排序 Kahn，O(V+E)）

## 遇到的问题

1. 第一次见图论题没头绪：不知道"能否学完所有课"等价于"有向图是否有环"
2. 入度减到 0 时写了 `q.push(i)`——push 的是**邻接表下标**而不是**课程号**，链式用例失败；示例 1 碰巧通过（下标 0 被重复出队凑够了数量），掩盖了 bug

## 解题要点

- **建模**：课程 = 节点；`prerequisites[i] = [ai, bi]` → 有向边 `bi → ai`；**有环 = 不可能**
- **Kahn 拓扑排序**：
  1. 建邻接表 + 统计每个节点入度
  2. 入度为 0 的节点入队（没有先修课）
  3. 出队时 `done++`，遍历后继，入度减 1，变 0 就入队
  4. 最后 `done == numCourses` → 无环
- 判环本质：环上的节点入度永远降不到 0，永远进不了队列
- 备选：**DFS 三色标记**（0 未访问 / 1 访问中 / 2 已完成），DFS 时遇到"访问中"的节点即存在环
- 易错点：入队时 push 的是**课程号**，不是邻接表下标
