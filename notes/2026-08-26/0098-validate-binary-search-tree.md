# 98. 验证二叉搜索树 —— 复盘笔记

状态：✅ 已解决

## 遇到的问题

一开始想到要保存当前子树的最小值和最大值，但不清楚这些范围应该怎样传递。更直接的方式是：辅助函数不返回子树范围，而是接收当前节点允许的开区间。

## 解题要点

- 辅助函数 check(node, lower, upper) 表示：node 必须满足 lower < node.val < upper。
- 根节点没有祖先限制，所以初始范围使用 long long 的最小值和最大值。
- 进入左子树后，上界收紧为当前节点值，下界保持不变。
- 进入右子树后，下界收紧为当前节点值，上界保持不变。
- 使用严格不等式，因此重复值不符合二叉搜索树定义。
- 只比较节点和直接父节点是不够的，后代节点还必须满足所有祖先施加的范围限制。
- 上下界使用 long long，避免节点值为 INT_MIN 或 INT_MAX 时边界判断出错。

## 复杂度

- 每个节点访问一次，时间复杂度 O(n)。
- 递归栈空间为 O(h)，h 是树的高度；最坏情况下为 O(n)。
