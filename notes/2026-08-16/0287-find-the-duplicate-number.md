# 287. 寻找重复数 —— 复盘笔记

状态：✅ 已解决（Floyd 环入口证明需继续复习）

## 遇到的问题

1. 开始时不清楚如何同时满足“不修改数组、O(1) 额外空间、O(n) 时间”
2. 需要把数组理解为映射关系 `index -> nums[index]`，才能把寻找重复数转换为寻找链表环入口
3. 对 Floyd 第二阶段为什么在环入口相遇理解较模糊，尤其容易误以为环内指针只会绕一次

## 解题要点

- 数组有 `n + 1` 个元素，取值只有 `[1, n]` 中的 `n` 种，根据鸽巢原理至少存在重复值
- 将每个下标视为节点，`nums[index]` 视为下一节点；从下标 `0` 不断跳转必然进入环
- 唯一重复值有至少两个不同下标指向它，因此它对应环入口
- 第一阶段使用快慢指针：慢指针每次跳一次，快指针每次跳两次，直到在环内相遇
- 第二阶段让一个指针从下标 `0` 重新出发，两个指针都每次跳一次，再次相遇的位置就是环入口
- 实现只读取 `nums`，不修改原数组

## 第二阶段距离关系

- 设起点到入口距离为 `a`，入口到第一阶段相遇点距离为 `b`，环长为 `L`
- 第一阶段相遇时有 `a + b = kL`，因此 `a = kL - b`
- 从相遇点继续走 `a` 步后，总环内位移为 `b + a = kL`，所以恰好回到入口
- 环内指针可能在此之前多次经过入口，但此时另一个指针仍在环外；只有走满 `a` 步时二者同时位于入口
- 这一证明仍需通过具体路径表格复习，避免只背公式

## 测试要点

- 最小规模 `[1,1]`
- 重复数为数值边界 `1` 或 `n`
- 同一数字出现两次或多次
- 较大输入验证线性性能
- 调用前后比较数组，确保实现没有修改 `nums`

## 复杂度

- 时间：O(n)
- 空间：O(1)
