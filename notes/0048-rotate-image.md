# 48. 旋转图像 —— 复盘笔记

状态：✅ 已解决（O(1) 额外空间）

## 遇到的问题

1. 直觉上知道"转置 + 行反转"，但不理解为什么这两步合起来就是顺时针 90°——用矩阵变换弄清楚了（见下）
2. 测试 5x5 用例曾报 FAIL，排查后发现是**测试用例的期望值写错了**（写成垂直翻转的结果），解法本身一次通过

## 解题要点

- **拆解**：顺时针 90° = 先转置（沿主对角线），再逐行反转
- **坐标映射**：
  - 旋转：(i, j) → (j, n-1-i)
  - 转置：(i, j) → (j, i)
  - 行反转：列号 i → n-1-i
  - 转置 + 行反转：`(i,j) → (j,i) → (j, n-1-i)` = 旋转 ✓
- **矩阵变换视角**（把坐标平移到矩阵中心后）：
  - 转置 = 主对角线反射：`T = [[0,1],[1,0]]`
  - 行反转 = 竖直轴反射：`H = [[-1,0],[0,1]]`
  - `H·T = [[0,-1],[1,0]]` = 顺时针 90° 旋转矩阵
  - 一般规律：两次反射 = 旋转 2θ（两镜面夹角为 θ）；det 从 -1×-1 = +1，方向性恢复
- **实现细节**：
  - 转置只交换上三角：`j` 从 `i+1` 开始（从 `i` 开始也正确，只是对角线上多几次自交换）
  - 行反转只到 `half-1`（`half = n/2`），奇数 n 的中间列不碰
- **亲戚公式**：
  - 逆时针 90° = 转置 + 列反转
  - 180° = 行反转 + 列反转

## 复杂度

- 时间：O(n²)
- 空间：O(1)
