# 25. K 个一组翻转链表

状态：⏳ 进行中

## 题目目标

给定链表头节点 `head` 和正整数 `k`，每 `k` 个节点为一组进行翻转；不足 `k` 个的最后一组保持原顺序。必须实际调整节点连接，不能只修改节点值。

要求：

- 原地修改链表连接关系
- 处理完整分组和最后不足 `k` 个的分组
- 目标复杂度为 `O(n)` 时间；进阶要求额外空间 `O(1)`

## 示例

```text
[1, 2, 3, 4, 5], k = 2 -> [2, 1, 4, 3, 5]
[1, 2, 3, 4, 5], k = 3 -> [3, 2, 1, 4, 5]
```

## 第一次提示：迭代分组翻转

使用一个哨兵节点 `dummy` 指向 `head`，这样第一组翻转时头节点也能按照普通分组处理。每轮维护 `groupPrev`，它指向当前分组之前的节点。

每轮分为三步：

1. 从 `groupPrev` 向后走 `k` 步找到 `kth`。如果中途遇到空指针，说明剩余节点不足 `k` 个，直接结束，保留剩余节点原顺序
2. 保存 `groupNext = kth->next`，它是当前分组之后的节点；然后只翻转区间 `[groupPrev->next, groupNext)`，不要越过 `groupNext`
3. 翻转后，原分组头节点变成尾节点，重新连接：`groupPrev->next` 指向 `kth`，下一轮的 `groupPrev` 更新为原分组头节点

翻转时可以让 `prev` 初始指向 `groupNext`，这样尾节点的 `next` 会自动接到下一组：

```text
prev = groupNext
curr = groupPrev->next

while (curr != groupNext) {
    next = curr->next
    curr->next = prev
    prev = curr
    curr = next
}
```

翻转完成后，`prev` 就是当前组的新头，也就是 `kth`；原来的组头保存为 `groupStart`，它现在是组尾，也是下一轮的 `groupPrev`。

以 `[1,2,3,4,5]`、`k=3` 为例：第一组边界是 `1,2,3`，`groupNext` 是 `4`。翻转后变成 `3->2->1->4`，下一轮从节点 `1` 之后开始检查；剩余 `4,5` 不足 3 个，因此保持原顺序。

推荐先写出“找第 `k` 个节点”的循环，再单独写“翻转到 `groupNext` 为止”的循环，最后处理两处连接关系。
