# 70 爬楼梯

## 已通过的代码

```cpp
class Solution {
public:
    int climbStairs(int n) {
        vector<int> dp(n+1, 0);

        dp[0] = 1;
        dp[1] = 1;

        for (int i = 2; i <= n; ++i) {
            dp[i] = dp[i-2] + dp[i - 1];
        }

        return dp[n];
    }
};
```

`dp[i]` 表示到达第 i 阶的方法数。最后一步可以从 i-1 爬一阶，或从 i-2 爬两阶，两类方案互不重叠，因此相加。`dp[0]=1` 表示空方案，便于统一递推；题目 n>=1，所以 dp[1] 的初始化合法。

时间 O(n)，空间 O(n)。提交通过来自用户反馈，本次记录未重新执行 C++ 测试。

## 矩阵快速幂暂缓复习

用户已阅读官解并询问位运算和奇偶拆幂，仍自评不清楚，先继续 198 打家劫舍。以后从以下问题接着学习，无需现在继续讲解：

- 为什么同时保存 dp[i] 与 dp[i-1]，以及矩阵 `M={{1,1},{1,0}}` 如何让它们前进一步？
- 为什么 `M^n` 的左上角等于 dp[n]？
- `n & 1` 是按位与，如何检查二进制最低位？它与逻辑与 `&&` 有什么不同？
- 偶数指数 `a^(2t)=(a*a)^t`；奇数指数 `a^(2t+1)=a*(a*a)^t`。为什么奇数时先把多出的一份乘入 ret？
- 能否手动模拟指数 13：依次选择 M、M^4、M^8，累计为 M^13？

复习时可检查不变量：每轮开始，`ret * a^剩余指数` 始终等于原来的目标矩阵幂。固定 2×2 矩阵的快速幂时间 O(log n)，额外空间 O(1)。
