## 状态定义与转移

`dp[i]` 表示必须以 `nums[i]` 结尾的非空连续子数组的最大和。

```cpp
dp[i] = max(dp[i - 1], 0) + nums[i];
```

前面的最佳和为正时接上它；为负时从当前元素重新开始；为零时两种选择等价。无论哪种选择，都包含当前元素，因此保持连续且非空。

`res` 表示所有已经计算的 `dp[i]` 中的最大值。题目不要求答案在最后一个元素处结束，因此最终返回 `res`。

## 修正后的代码

```cpp
class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        int n = static_cast<int>(nums.size());
        vector<int> dp(n);
        dp[0] = nums[0];
        int res = dp[0];

        for (int i = 1; i < n; ++i) {
            dp[i] = max(dp[i - 1], 0) + nums[i];
            res = max(res, dp[i]);
        }

        return res;
    }
};
```

这与用户使用 INT_MIN 初始化后再更新 res 的版本等价。题目保证数组非空。

## 本轮错误复盘

1. 初版正确计算了 dp，但直接返回 `dp[n - 1]`，误把固定结尾的最优解当作全局答案。
2. 加入历史最大值 res 后，返回语句仍是 `return dp[n - 1]`，因此结果没有变化。
3. 最终改为 `return res`。

```text
nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]
dp   = [-2, 1, -2, 4,  3, 5, 6,  1, 5]
```

最后的 dp 值为 5，但历史最大值为 6，对应 `[4,-1,2,1]`。

## 边界与复杂度

- 单元素 `[1]` 返回 1，`[-5]` 返回 -5。
- 全负数 `[-3,-2]` 返回 -2，不能把答案初始化为 0，因为不允许选空子数组。
- 全零 `[0,0]` 返回 0。
- `[5,4,-1,7,8]` 返回 23。
- 时间 O(n)，当前 dp 数组版本额外空间 O(n)。每次只读取前一个状态，后续可学习用单个变量将额外空间压缩为 O(1)。分治进阶尚未学习。

## 记忆

`dp[i]`：以 i 结尾最好是多少；`res`：所有结尾中最好是多少。维护了答案变量后，最后也要返回它。
