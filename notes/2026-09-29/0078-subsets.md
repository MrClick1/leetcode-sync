# 78. 子集

状态：2026-09-29 用户确认下面的实现已通过 LeetCode；代码复核正确，临时目录中的 C++17 校验 508 个输入通过。同一个对象多次调用、输入不变、path 恢复为空和已返回答案不受后续调用影响均已检查。未在仓库建立本地题目脚手架。

## 用户通过的实现

```cpp
class Solution {
public:
    vector<vector<int>> res;
    vector<int> path;

    void backtracking(const vector<int>& nums, int startIndex) {
        // 每个节点都要存放结果
        res.push_back(path);

        for (int i = startIndex; i < (int)nums.size(); ++i) {
            path.push_back(nums[i]);
            backtracking(nums, i + 1);
            path.pop_back();
        }
    }

    vector<vector<int>> subsets(vector<int>& nums) {
        res.clear();
        path.clear();
        backtracking(nums, 0);
        return res;
    }
};
```

## 本轮复核

本轮未发现算法或边界问题，不需要修改解法。

- 每次调用入口的 path 都是一个合法子集，立即复制保存；首次进入时 path 为空，因此自然包含空集。
- startIndex 表示本次还可选择的起始下标。选择 nums[i] 后只递归到 i+1，路径中的原始下标严格递增，既避免重复使用元素，也避免把同一个子集的不同顺序重复收集。
- 下层返回后 pop_back 撤销本层添加的元素，进入下一候选前恢复原来的 path。
- nums 使用 const 引用，无须每层复制，也不会修改原数组。
- 入口清空 res/path，避免复用同一个 Solution 对象时旧答案累积。清空只在 subsets 入口执行，不能放进每个递归调用。

## 为什么不写显式终止条件也正确

startIndex==nums.size() 时，当前 path 仍应先保存；随后的 for 无候选可遍历，函数自然结束并返回上一层。

例如选完 [1,2,3] 后进入 startIndex=3 的调用，先保存完整子集，再自然返回。若在保存前添加 if (startIndex==nums.size()) return，则会漏掉这些合法子集。

## 为什么必须传 i+1

下一层要从本次实际选中的下标 i 后面继续，而不只是从本层最初的 startIndex 后面继续。

对于 nums=[1,2,3]，入口 startIndex=0：

- i=0 选 1，下一层从 1 开始，可继续选择 2、3。
- i=1 选 2，下一层从 2 开始，只可继续选择 3。
- i=2 选 3，下一层从 3 开始，无后续候选。

nums 的数字不要求排序；递增的是原始下标，不是数值。例如 nums=[3,1] 返回 []、[3]、[3,1]、[1]，同样是合法答案。题目保证数字互不相同，所以无需 used、set 或额外值去重。

## 示例中的收集顺序

对 nums=[1,2,3]，用户实现按深度优先顺序得到：

```text
[] → [1] → [1,2] → [1,2,3] → [1,3] → [2] → [2,3] → [3]
```

这个箭头表示依次收集的答案，不代表 path 始终只增加。不同分支之间通过 pop_back 撤销已有选择。输出顺序可以与题面不同。

## 与 46. 全排列对照

| 对照点 | 46. 全排列（path + used 版本） | 78. 子集（本实现） |
|---|---|---|
| 是否考虑排列顺序 | [1,2] 与 [2,1] 是不同排列 | 两者代表同一个子集 |
| 何时收集 | path 长度达到 n | 每次递归进入都收集，包括空集 |
| 下一层的候选 | 从 0 遍历，用 used 排除已选元素 | 从本次选择的 i+1 开始 |
| 撤销 | 删除 path 末尾并解除 used | 删除 path 末尾 |
| 答案数量 | n! | 2^n |

不把排列的完整长度终止条件照搬到子集；不把子集的 i+1 候选限制照搬到排列。

## 复杂度

每个数字都有选或不选两种可能，共 2^n 个子集。保存每个 path 需要复制其中的元素，全部子集的元素总数为 n×2^(n-1)，时间 O(n×2^n)。

不计返回结果：path 与递归调用栈各占 O(n)，辅助空间 O(n)。计入返回结果，输出存储为 O(n×2^n)。
