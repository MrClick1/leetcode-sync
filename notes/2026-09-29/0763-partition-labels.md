# 763. 划分字母区间

## 用户通过版本

```cpp
class Solution {
public:
    vector<int> partitionLabels(string s) {
        int n = (int)s.size();
        vector<int> alpha(26, -1);

        for (int i = 0; i < n; ++i) {
            char c = s[i];
            alpha[c - 'a'] = i;
        }

        int curMaxLeap = 0;
        int curStart = 0;
        vector<int> res;

        for (int i = 0; i < n; ++i) {
            char c = s[i];
            curMaxLeap = max(curMaxLeap, alpha[c - 'a']);

            if (i == curMaxLeap) {
                res.push_back(i - curStart + 1);
                curStart = i + 1;
            }
        }

        return res;
    }
};
```

保留用户通过实现。curMaxLeap 不再表示跳跃距离，而是当前片段所有已扫描字母的最晚出现下标；为避免与 45 混淆，复习时可改名 end，alpha 可改名 last，但命名修改不是正确性修复。

## 初稿问题

### 字符表大小不是字符串长度

```cpp
vector<int> alpha(n, -1);
alpha[s[i] - 'a'] = i;
```

下标是字母编号，范围为 0 到 25，与字符串长度无关。例如 s="z" 时 n=1，但访问 alpha[25]，发生越界。应使用 vector<int> alpha(26, -1)。按 i 递增遍历时，直接赋值会保留最后出现位置，无需再取 max。

### 不能先切分，再扩大旧边界

初稿沿用跳跃游戏 II 的 curMaxLeap/nextMaxLeap 双边界：在 i==curMaxLeap 时先记录片段，然后才将 curMaxLeap 更新为 nextMaxLeap。

本题的边界不是固定的一层可达范围，而是当前片段内所有已扫描字母的最后出现位置的最大值。新字母可能要求把片段继续延长；必须先更新这个边界，再判断能否切分。

例如 s="aba"，alpha['a'-'a']=2，alpha['b'-'a']=1。初稿在 i=0 时将 nextMaxLeap 更新为 2，却因为旧 curMaxLeap=0 而记录长度 1，然后才把 curMaxLeap 更新为 2。最后得到 [1,2]，对应 "a"、"ba"，字母 a 被拆到两个片段中，不合法。正确结果为 [3]。

### 后续片段不能被可达性判断跳过

初稿的 if (i<=curMaxLeap) 是跳跃游戏中的可达性过滤，本题应扫描每个字符，不存在“当前位置不可达”。例如 s="ab"，处理 i=0 后 curMaxLeap 仍为 0，i=1 不满足条件，被跳过；初稿返回 [1]，漏掉第二个片段。

## 正确维护一个片段的右边界

只需要 start 和 end 两个下标，不需要当前层与下一层两套边界。

- start：当前尚未记录片段的起点。
- end：当前片段里所有已扫描字母，最后出现位置的最大值。
- 每轮先更新 end=max(end,alpha[s[i]-'a'])。
- 若 i==end，当前片段所有字母都不会在后面出现，可以记录长度 end-start+1，并令 start=i+1。

```cpp
class Solution {
public:
    vector<int> partitionLabels(string s) {
        int n = static_cast<int>(s.size());
        vector<int> last(26, -1);
        for (int i = 0; i < n; ++i) {
            last[s[i] - 'a'] = i;
        }

        int start = 0;
        int end = 0;
        vector<int> res;
        for (int i = 0; i < n; ++i) {
            end = max(end, last[s[i] - 'a']);
            if (i == end) {
                res.push_back(end - start + 1);
                start = i + 1;
            }
        }
        return res;
    }
};
```

上述是用户通过算法的命名整理版，没有改变逻辑。切分后不重置 end 也可以：下一字符在 i=end+1，而 last[s[i]-'a']>=i，每轮更新会自动建立新的片段右边界。

## 不靠背模板：从题目限制推出代码

1. 片段包含某个字母，就必须包含它后面所有出现，否则该字母会跨片段；因此需要知道每个字母最后出现的位置。
2. 多个字母各有延伸要求，必须全部满足，当前片段边界取这些最后位置的最大值。
3. 片段延伸期间会遇到新的字母，新字母可能要求继续延伸；所以每扫描一个字符，先更新 end，而不能只检查片段开头的字母。
4. 更新后 i<end，说明有字母还没有结束，不能切分；i==end，说明本段所有字母都已经结束，立即切分。

每轮更新之后 end>=i，因为当前字符的最后位置至少是 i。因此本算法不会出现扫描越过更新后边界却没记录的情况。

## 模拟 abacbcde

下标与字母为 0:a、1:b、2:a、3:c、4:b、5:c、6:d、7:e；最后位置为 a=2、b=4、c=5、d=6、e=7。

| i | 字母 | 最后位置 | 更新后的 end | 处理 |
|---|---|---|---|---|
| 0 | a | 2 | 2 | 至少包含到最后一个 a |
| 1 | b | 4 | 4 | 新遇到 b，需要进一步延长 |
| 2 | a | 2 | 4 | a 虽然结束，但 b 尚未结束 |
| 3 | c | 5 | 5 | 新遇到 c，再次延长 |
| 4 | b | 4 | 5 | b 虽然结束，但 c 尚未结束 |
| 5 | c | 5 | 5 | i==end，记录 abacbc 的长度 6 |
| 6 | d | 6 | 6 | 记录 d 的长度 1 |
| 7 | e | 7 | 7 | 记录 e 的长度 1 |

结果为 [6,1,1]。不要在 i=2 时因 a 结束就切分，切分条件检查的是本段所有字母的最大要求。

## 为什么尽早切分能得到最多片段

在 i<end 时，已扫描的某个字母还会在后面出现，不能现在切分。在 i==end 时，当前片段所有字母的最后一次出现都已经扫描到，这就是最早合法切分点。更早不合法，更晚只会合并本可分开的片段；因此在最早合法位置切分，再对后缀重复处理，可以得到最多片段。

## 与 45. 跳跃游戏 II 区分

45 的 end 是扫描一层时固定的边界，farthest 累计下一层，扫描完旧边界后才推进层数。本题的 end 是当前片段的约束边界，必须随每个新字母立即更新，只有扫描到更新后的边界才允许切分。两题都取最远位置，但变量代表的含义与结束条件不同，不能只照搬代码结构。

记忆：先找到每个字母最后在哪里，再一边扫描一边扩大本段；所有字母都结束了，才切一刀。

复习时先不看代码，解释 alpha、curStart、curMaxLeap 各代表什么，再模拟 abacbcde 并说明为什么下标 2、4 不能切分。能从“不能跨段”的约束推导 max 更新与相等切分条件，比只记住代码结构更可靠。

时间 O(n)，字母表固定为 26 个小写字母时，除返回结果外的额外空间 O(1)。
