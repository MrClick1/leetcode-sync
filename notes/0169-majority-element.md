# 169. 多数元素 —— 复盘笔记

状态：✅ 已解决

## 遇到的问题

1. 第一版尝试用快速选择寻找排序后下标为 `n / 2` 的元素，方向可行，但 `partition` 没有按区间缩小，边界与比较逻辑也比较复杂
2. 改用 Boyer–Moore 投票算法后，第一次选择候选人时只更新了 `candidate`，没有把 `count` 设为 1，导致程序实际上总是返回数组最后一个元素
3. 原测试中的多数元素恰好都位于数组末尾，因此没有暴露上述错误；加入 `{1, 1, 2}` 后覆盖了“多数元素不在末尾”的情况

## 解题要点

- 多数元素出现次数大于 `n / 2`，把不同元素两两抵消后，最终剩下的候选人一定是多数元素
- 维护候选人 `candidate` 和票数 `count`
- `count == 0` 时选择当前元素作为新候选人，并让它获得第一票
- 当前元素等于候选人时加票，否则减票
- 题目保证多数元素一定存在，因此遍历结束后可以直接返回候选人；如果没有这个保证，还需要第二次遍历验证出现次数

## 测试要点

- 单元素和全部相同
- 多数元素位于开头、中间或末尾
- 包含负数和数值边界
- 回归用例：`{1, 1, 2}`，防止遗漏新候选人的第一票

## 复杂度

- 时间：O(n)
- 空间：O(1)
