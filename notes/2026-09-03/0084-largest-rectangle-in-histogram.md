# 84. 柱状图中最大的矩形 —— 复盘笔记

状态：✅ 已解决（本地固定测试与 10000 组随机对拍通过）

## 从矩形面积转化为边界问题

一段连续柱子能够组成的最高矩形，其高度等于这一段中的最小柱高。因此，可以枚举每根柱子作为矩形的最低柱子，固定高度后，向左右尽可能扩展。

- 比当前柱子高或一样高的柱子，可以包含在矩形中。
- 遇到严格更矮的柱子时，必须停止，且不能包含这根边界柱子。

定义：

```cpp
left[i]   // 左边第一个严格更矮的柱子的下标；不存在则为 -1
right[i]  // 右边第一个严格更矮的柱子的下标；不存在则为 n
```

矩形实际覆盖闭区间 `[left[i] + 1, right[i] - 1]`，所以：

```cpp
int width = right[i] - left[i] - 1;
int area = heights[i] * width;
```

遍历所有柱子，取这些面积中的最大值即可。逐根向两边扫描虽然直观，但最坏需要 O(n²) 时间；本题用单调栈将边界查找降为 O(n)。

## 当前实现：两趟单调栈

当前解答分别使用 `stk1` 和 `stk2` 找左右边界，保留了用户的两栈写法，没有改成单栈或哨兵解法。

栈里保存的是下标，不是高度；对应的高度从栈底到栈顶严格递增。

### 从左向右找左边界

遍历到下标 `i` 时：

1. 当栈不为空，且栈顶高度大于等于 `heights[i]` 时，弹出栈顶。
2. 弹出完成后，如果栈不为空，栈顶就是左边第一个严格更矮的柱子。
3. 如果栈为空，令 `left[i] = -1`。
4. 将当前下标 `i` 入栈，供后面的柱子使用。

```cpp
while (!stk1.empty() && heights[stk1.top()] >= height) {
    stk1.pop();
}
```

被弹出的柱子为什么以后也可以不用？对于更右边的柱子，当前柱子比被弹出的柱子更近，而且不比它高。如果被弹出的柱子能成为严格更矮的候选，当前柱子也能成为候选，并且位置更近。

### 从右向左找右边界

遍历顺序改为 `i = n - 1` 到 `0`，其余逻辑对称。栈为空时令 `right[i] = n`。

当前代码使用一个新的空栈 `stk2`，不需要清空 `stk1`；如果选择复用同一个栈，就必须先清空再开始第二趟遍历。

最后一趟遍历根据左右边界计算面积并更新 `maxArea`。

## 示例推演

对于 `heights = [2, 1, 5, 6, 2, 3]`：

| 下标 i | 高度 | left[i] | right[i] | 宽度 | 面积 |
|---|---|---|---|---|---|
| 0 | 2 | -1 | 1 | 1 | 2 |
| 1 | 1 | -1 | 6 | 6 | 6 |
| 2 | 5 | 1 | 4 | 2 | 10 |
| 3 | 6 | 2 | 4 | 1 | 6 |
| 4 | 2 | 1 | 6 | 4 | 8 |
| 5 | 3 | 4 | 6 | 1 | 3 |

最大面积为 10，对应下标 2 到 3 的柱子，高度取 5。

找左边界时，遍历到下标 4、高度 2，栈中下标为 `[1, 2, 3]`，对应高度 `[1, 5, 6]`。先弹出高度 6 和 5，剩下高度 1，因此 `left[4] = 1`。

## 容易混淆的地方

### 1. 为什么是大于等于，而不是只比较大于

本实现要求左右边界都严格更矮，所以相等高度也要弹出。一样高的柱子不会阻止矩形扩展。

例如 `[2, 2, 2]`：每根柱子都应该能覆盖整个数组，面积为 6。如果两趟查找都只在 `>` 时弹栈，就会把相邻的等高柱子当成边界，导致宽度过小。

其他单调栈写法可能采用不同的等高处理约定，不能脱离边界定义直接替换比较符号。

### 2. 为什么边界默认值是 -1 和 n

这两个值是数组外的虚拟边界，不用于访问 `heights`。

- 左边没有更矮的柱子：从下标 0 开始，因此左侧阻挡位置记为 -1。
- 右边没有更矮的柱子：可以到下标 n - 1，因此右侧阻挡位置记为 n。
- 两边都没有阻挡：宽度为 `n - (-1) - 1 = n`。

不能把右侧默认边界设为 n - 1，因为最后一根柱子本身仍然可以包含在矩形内。

### 3. 下标、高度、宽度要分开

- `stk1.top()` 是下标。
- `heights[stk1.top()]` 才是高度。
- `right[i] - left[i] - 1` 是完整矩形的宽度，不是单侧的扩展距离。

原注释中 `4 - (n = 5) = -1` 不能用来解释宽度，已改为“右边没有更矮的柱子，矩形可延伸到下标 n - 1”。本次只整理了注释和格式，没有修改算法逻辑。

### 4. 边界数组和整数范围

- `vector<int> left(n), right(n)` 创建了 n 个元素；当前代码在每次遍历中都会通过 if/else 写入对应边界，没有遗漏赋值。
- `n` 转换为 int 后，反向循环 `i >= 0` 不会发生无符号整数下溢。
- 本题最大面积为 `100000 * 10000 = 1000000000`，在当前环境的 32 位 int 范围内，使用 int 足够；如果题目扩大数值范围，应在乘法前转为 long long。

## 复杂度

- 时间复杂度：O(n)。每趟遍历中，每个下标最多入栈一次、出栈一次，最后再进行一趟面积计算。
- 额外空间复杂度：O(n)。使用两个长度为 n 的边界数组，以及最多保存 O(n) 个下标的两个栈。
- 输入数组保持不变。
