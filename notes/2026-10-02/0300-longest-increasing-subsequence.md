# 300 最长递增子序列

2026-10-02 用户自行给出 O(n²) 动态规划实现，并明确反馈力扣提交通过。按当前学习安排先完成 Hot 100 DP 首轮，进阶 O(n log n) 解法留待后续。

## 用户通过代码

```cpp
class Solution {
public:
    int lengthOfLIS(vector<int>& nums) {
        int n = (int)nums.size();
        int res = 1;

        vector<int> dp(n, 1);

        for (int i = 1; i < n; ++i) {
            for (int j = 0; j < i; ++j) {
                if (nums[i] > nums[j]) {
                    dp[i] = max(dp[i], dp[j] + 1);
                    res = max(res, dp[i]);
                }
            }
        }

        return res;
    }
};
```

## 状态与递推

dp[i] 表示必须以 nums[i] 结尾的最长严格递增子序列长度。它不是前 i+1 个元素中任意结尾的最长长度；固定结尾才能用 nums[j] 判断能否接上 nums[i]。

每个元素自己就是长度 1 的递增子序列，所以所有 dp 初始为 1。枚举所有 j<i，保证相对顺序；只有 nums[j]<nums[i] 才能把 nums[i] 接到以 nums[j] 结尾的最优序列后面，得到 dp[j]+1，在候选中取最大值。子序列不要求连续，因此 j 不限于 i-1。

每条长度大于 1 且以 i 结尾的递增子序列，都有一个倒数第二个下标 j<i，且 nums[j]<nums[i]；循环枚举了这些候选，不漏方案。等值元素不能延长严格递增序列。

最终答案是所有 dp[i] 的最大值，因为最优序列可以结束在任意位置，不能直接返回 dp[n-1]。原代码把 res 更新放在可连接分支内仍然正确：res 初始 1，未进入分支时当前 dp[i] 也为 1，不会遗漏更大答案。

## 手算示例与边界

```text
nums = [10,9,2,5,3,7,101,18]
dp   = [ 1,1,1,2,2,3,  4, 4]
res  = 4
```

例如 nums[i]=7 时，前面的 2、5、3 都能作为前驱，分别产生长度 2、3、3，所以 dp[i]=3。结尾状态只记录长度，不要求还原具体序列。

nums=[1,2,3,0] 时 dp=[1,2,3,1]，答案为 3，最后状态却为 1；说明返回历史最大值的必要性。

nums=[7,7,7] 或严格递减时，所有状态保持 1。n=1 时循环不进入，res=1 正确。本题保证数组非空，无需强行增加空数组处理。

## 复杂度与复习

内层遍历次数为 1+2+…+(n-1)，时间 O(n²)，辅助空间 O(n)。本轮静态核对状态、递推、初始化、边界和结果收集，未重新编译运行；力扣通过来自用户反馈。

复习时先说清“以 i 结尾”，再问“前一个元素可以在哪”：下标必须小于 i，数值必须小于 nums[i]。找到候选后用 dp[j]+1 更新，并维护所有结尾中的最大值。
