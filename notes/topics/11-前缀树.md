## 节点含义

Trie 的一个节点表示某个前缀。节点通常包含：

```cpp
struct TrieNode {
    TrieNode* children[26]{};
    bool isEnd = false;
};
```

- `children[i]` 指向添加字符 `'a'+i` 后的新前缀。
- `isEnd` 表示当前前缀本身是否是一个完整单词。
- 仅仅走到某个节点不代表单词存在，还必须检查 `isEnd`。

## 三个操作

### `insert(word)`

从根开始逐字符向下走；子节点不存在时创建。处理完最后一个字符后把当前节点的 `isEnd` 设为 `true`。

### `search(word)`

逐字符查找。中途缺少子节点则返回 `false`；全部字符存在后，还要确认最终节点 `isEnd == true`。

### `startsWith(prefix)`

逐字符查找；只要整段前缀路径存在就返回 `true`，不要求最终节点是单词结尾。

## `search` 与 `startsWith` 的区别

假设只插入了 `apple`：

```text
search("app")        → false
startsWith("app")    → true
search("apple")      → true
```

## 复杂度

设操作字符串长度为 `L`：

- 插入：`O(L)`。
- 完整单词查询：`O(L)`。
- 前缀查询：`O(L)`。
- 总空间：所有新建字符节点数量，最坏与插入字符串总长度成正比。
