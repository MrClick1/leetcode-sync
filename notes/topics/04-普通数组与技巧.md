## 912. 排序数组（排序补充练习）

每层只处理 [left,right]：基准放末尾，i 标记小于基准区域的末尾，j 从 left 扫描到 right-1。扫描后将基准放到 i+1，再递归 [left,pos-1]、[pos+1,right]。严格 < 的二路划分在全相等输入上会退化，随机选基准无法消除这个问题。先掌握区间不变量，再继续第 347 题快速选择。

堆排序也已通过：自底向上建大顶堆，将根交换到末尾，缩小堆后修复根。len 表示数量时用 child<len，表示末尾下标时用 child<=len，不可混用。递归向下调整占 O(log n) 栈空间，迭代版为 O(1)。归并已讨论 temp 合并后写回 nums 的问题，尚待用户确认最终实现。

## 56. 合并区间

排序后，新区间只可能与结果的最后一段重叠。若新起点不超过最后一段的终点，则取两个终点的最大值；否则加入新区间。端点相等也算重叠，完全包含时不能直接覆盖终点。

## 189. 轮转数组

先令 k %= n。将原数组看作 A B，其中 B 长度为 k；整体反转变成 reverse(B) reverse(A)，再分别反转前 k 个和剩余元素，得到 B A。k 为 0 时可以提前返回。三次线性反转仍是 O(n) 时间。

## 41. 缺失的第一个正数


长度为 `n` 时，答案一定在 `[1,n+1]`。把数组本身当作哈希表：数字 `x` 应放在下标 `x-1`。

```cpp
while (nums[i] >= 1 &&
       nums[i] <= n &&
       nums[i] != nums[nums[i] - 1]) {
    swap(nums[i], nums[nums[i] - 1]);
}
```

- 范围检查必须写在数组二次下标访问之前，利用 `&&` 短路保证安全。
- 第三个条件防止重复数字在相同位置之间无限交换。
- 交换后当前位置出现新值，因此要继续使用 `while` 检查。
- 二刷曾把范围检查放在外层 if，交换后遇到负数仍访问目标下标而越界；范围条件必须进入 while。每次交换新增一个正确位置，总交换次数 O(n)。

## 136. 只出现一次的数字

异或性质：

```text
a ^ a = 0
a ^ 0 = a
满足交换律和结合律
```

把所有元素依次异或，成对元素全部抵消，最终只剩出现一次的数字。

2026-10-04 用户自行实现 res=0、遍历 res^=nums[i] 并反馈力扣通过。res 是已处理前缀的累计异或，不是中途已经确认的答案。交换律与结合律保证非相邻的重复数也能抵消，零和负数同样适用。本轮 C++17 对 3933 个合法输入与频次参考一致，见日期笔记；原 2026-08-14 记录保留，不重复计数。

## 169. 多数元素

把不同元素两两抵消。多数元素出现次数超过一半，因此最终候选人一定是它：

```text
count == 0 → 选择当前元素作为候选人
当前值等于候选人 → count++
否则 → count--
```

选择新候选人时必须让它获得第一票。题目不保证多数元素存在时，还需要第二次遍历验证。

2026-10-04 用户自行实现并反馈通过：首元素初始化 res、cnt=1，从下标 1 扫描。cnt 是不同元素配对抵消后的候选人剩余数量，不是原数组频次。静态核对与手动模拟，未新增本地编译测试；二刷不重复计数。

## 191 位1的个数

用户已看懂并自行实现 n&=(n-1)，提交通过。减一把最低位的 1 清零、右侧 0 变 1，与原数做按位与恰好只清一个 1。通用参考为反复累加 n&1，再 n>>=1；前者按 1 的数量循环，后者按有效位数循环。本轮两种 C++17 实现在 110104 个合法输入上与除二取余参考一致。按补充练习收录，不声称属于 Hot 100 原清单。

## 461 汉明距离

## 338 比特位计数

用户清位、右移两种 DP 均已力扣通过。dp[i] 是整数 i 中 1 的个数，分别从 dp[i&(i-1)]+1 与 dp[i>>1]+(i&1) 得到；依赖值都小于 i，按整数正序计算即可。两份代码残留的 count1 没有被调用，可删除，不会让 DP 退回逐个清位统计。C++17 对 n=0、1、2、5、100000 的全部结果核对一致，共 100013 个成对位置。最高有效位方法仅作学习参考，本题作为非 Hot 100 的补充练习收录。
