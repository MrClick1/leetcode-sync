## 使用方法

1. 先阅读某个专题的“共性框架”，明确这类题通常在维护什么状态。
2. 根据题目表格回忆核心方法和复杂度，不看代码口述一遍。
3. 再打开对应的日期笔记，复习当时遇到的错误和最终实现。
4. 对标记为“需巩固”的题目优先重写，不只阅读答案。

题目按主要解法归入一个主分类；同时涉及其他结构时，会在相关专题中作为“交叉题目”引用。

## 复杂度速览

- 哈希、BFS、树遍历类题目通常目标为 `O(n)` 或 `O(rows * cols)`。
- 排序后双指针的三数之和为 `O(n²)`；不要误写成 `O(n)`。
- 链表重连通常是 `O(n)` 时间、`O(1)` 辅助空间；合并 K 链表使用堆为 `O(N log k)`。
- 单调栈让每个元素最多入栈、出栈一次，因此可以从嵌套循环得到 `O(n)`。
