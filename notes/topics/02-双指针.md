# 双指针

## 共性框架

双指针不是固定代码，而是利用数据的方向性缩小搜索范围。常见形式：

- 左右指针：从区间两端向中间移动。
- 快慢指针：以不同速度在隐式链表中移动。
- 多区域指针：维护已经处理好的几个区间。

使用前要明确每个指针两侧分别代表什么，以及每次移动为什么不会漏掉答案。

## 15. 三数之和

先排序，再固定 `nums[i]`：

```text
sum < 0 → left++
sum > 0 → right--
sum = 0 → 记录答案，移动两端并跳过重复值
```

- 固定值要跳过与前一个相同的 `nums[i]`。
- 找到答案后左右两侧都要去重。
- 相邻位置访问必须先确认 `left < right`，避免 `left+1` 或 `right-1` 越界。
- `nums[i] > 0` 时可以结束，因为后面的数不会更小。

## 31. 下一个排列

记成三个动作：**找转折、换大一点、后缀最小化**。

1. 从右向左找第一个 `nums[i] < nums[i+1]`。
2. 从右向左找第一个严格大于 `nums[i]` 的元素并交换。
3. 反转 `i+1` 之后的非递增后缀，使它变成最小升序后缀。

如果找不到转折点，说明当前是最大排列，直接反转整个数组。

## 75. 颜色分类

荷兰国旗不变量：

```text
[0, left)       全是 0
[left, cur)     全是 1
[cur, right]    尚未处理
(right, n)      全是 2
```

- 遇到 `0`：和 `left` 交换，`left++`、`cur++`。
- 遇到 `1`：`cur++`。
- 遇到 `2`：和 `right` 交换，`right--`，但 `cur` 暂时不动，因为换回来的值尚未检查。

## 287. 寻找重复数

把数组看成隐式链表：

```text
下标 index → 下一节点 nums[index]
```

不同下标指向同一个重复值，使路径形成环；重复值对应环入口。

- 第一阶段：快慢指针在环内相遇。
- 第二阶段：一个指针回到下标 `0`，两个指针每次走一步，再次相遇于入口。
- 设起点到入口为 `a`、入口到第一次相遇点为 `b`、环长为 `L`，有 `a+b=kL`，因此相遇点再走 `a` 步也到入口。
