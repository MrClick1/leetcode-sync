# 图论与 BFS

## BFS 通用模板

```text
准备队列 → 源点入队并标记 → 取队首并 pop → 扩展邻居 → 邻居入队即标记
```

如果需要最短步数或时间，按层处理；如果有多个同时生效的源点，把它们全部放入初始队列。

## 200. 岛屿数量

外层扫描发现一个尚未访问的 `'1'`，答案加一，再用 BFS 把整座岛改成 `'0'`。

- 上下移动检查行边界，左右移动检查列边界。
- 节点入队时立即改成 `'0'`，否则多个邻居可能让它重复入队。
- 一次 BFS 只负责淹没当前连通块，结束后继续外层扫描。

第一次练习记录：[2026-08-12 笔记](../2026-08-12/0200-number-of-islands.md)。

## 207. 课程表

把先修关系建成有向图：先修课指向后续课程。

1. 统计每个节点入度。
2. 所有入度为零的课程入队。
3. 每弹出一门课程，就让它指向课程的入度减一。
4. 新入度变为零时加入队列。
5. 最终处理节点数等于课程总数，说明不存在环。

Kahn 算法本质是不断删除当前没有依赖的节点。

## 994. 腐烂的橘子

这是多源 BFS：所有初始腐烂橘子同时位于第 0 层。

```text
收集腐烂源点 → 统计新鲜橘子 → 分层扩散
→ 新鲜橘入队即变 2 → 最后检查剩余数量
```

- `queue.size()` 在每分钟开始时保存，当前层处理完才让分钟数增加。
- 没有新鲜橘子时答案为 `0`。
- 队列耗尽后仍有新鲜橘子时答案为 `-1`。
- 不应从每个腐烂橘子分别 BFS 再取最大值，因为所有腐烂源会同时扩散。

## 单源、连通块与多源的区别

| 类型 | 初始队列 | 典型目标 |
|---|---|---|
| 单源 BFS | 一个起点 | 从一个位置出发的最短距离 |
| 连通块 BFS | 外层每发现一个未访问节点就启动一次 | 统计岛屿或连通分量 |
| 多源 BFS | 所有源点同时入队 | 到最近源的距离、同步扩散时间 |

## BFS 检查清单

- 是否执行了 `front()` 后的 `pop()`？
- 是在入队时还是出队时标记？通常应入队即标记。
- 当前问题是单源、多个连通块，还是多源同时扩散？
- 需要按节点计数还是按层计时？
- 邻居的行列边界是否对应正确？
- BFS 结束后是否需要检查未访问目标？
