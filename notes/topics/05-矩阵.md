# 矩阵

## 共性框架

矩阵题最常见的问题不是算法本身，而是行列含义、边界收缩和原地修改顺序。建议统一命名：

```cpp
int rows = matrix.size();
int cols = matrix[0].size();
```

访问 `matrix[row][col]` 时，上下移动检查 `row` 与 `rows`，左右移动检查 `col` 与 `cols`。

## 48. 旋转图像

顺时针旋转 90° 可以拆成：

```text
沿主对角线转置 → 每一行反转
```

转置时只遍历 `j > i` 的一侧，否则同一对元素会交换两次。

## 54. 螺旋矩阵

维护 `top、bottom、left、right` 四个边界，每轮依次走：上边、右边、下边、左边。

- 走完一边就收缩对应边界。
- 走下边前检查 `top <= bottom`。
- 走左边前检查 `left <= right`。
- 循环条件为 `top <= bottom && left <= right`。

## 73. 矩阵置零

用 `matrix[row][0]` 标记整行，用 `matrix[0][col]` 标记整列；再用两个布尔变量保存第一行、第一列原本是否含零。

正确顺序：

1. 先记录第一行和第一列。
2. 扫描内部区域并打标记。
3. 根据标记清零内部区域。
4. 最后处理第一行和第一列。

标记尚未使用完时不能提前清零，否则会丢失信息。

## 240. 搜索二维矩阵 II

从右上角开始：

```text
当前值 > target → 左移，排除当前列
当前值 < target → 下移，排除当前行
```

右上角左边更小、下边更大，因此每一步都能安全排除一整行或一整列。

## 矩阵题检查清单

- `rows` 和 `cols` 是否写反？
- 访问相邻格子前是否先完成边界判断？
- 输入是否保证非空，能否安全访问 `matrix[0]`？
- 原地标记是在信息读取之前还是之后修改？
- 单行、单列、方阵和非方阵是否都覆盖？
