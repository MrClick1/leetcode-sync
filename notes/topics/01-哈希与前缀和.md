# 哈希与前缀和

## 共性框架

哈希结构通常负责把“需要反复查找的信息”保存成平均 `O(1)` 的映射：

```text
值 → 下标
特征 → 一组原对象
前缀和 → 出现次数
元素 → 是否出现
```

复习时先问三个问题：哈希表的 key 表示什么、value 表示什么、应该先查询还是先插入。

## 1. 两数之和

- 保存已经遍历过的“数值 → 下标”。
- 当前值为 `x` 时查询 `target - x`。
- 必须先查询、再保存当前值，这样不会把同一个位置和自己配对。
- 重复值不需要特殊处理，例如 `[3,3]` 会在第二个 `3` 找到第一个下标。

记忆句：**当前数字问哈希表：我的补数以前出现过吗？**

## 49. 字母异位词分组

- 互为异位词的字符串排序后相同，因此排序结果可以作为 key。
- 哈希表类型是 `unordered_map<string, vector<string>>`。
- `groups[key].push_back(original)` 会在 key 不存在时自动创建空分组。
- 进阶可以使用 26 个字符计数构造 key，把排序开销降为线性字符扫描。

记忆句：**把顺序不同但本质相同的对象，转换成同一个标准形态。**

## 128. 最长连续序列

- 集合负责去重和判断某个数是否存在。
- 只有 `num - 1` 不存在时，`num` 才是一段连续序列的起点。
- 从每个起点向后扩展；非起点直接跳过。
- 如果遍历原数组，重复起点可能重复扫描长序列并超时，因此应遍历去重后的集合。

记忆句：**只从没有前驱的数字出发。**

## 560. 和为 K 的子数组

当前前缀和为 `prefix`，若之前存在 `prefix - k`，两者之间的连续子数组和就是 `k`：

```cpp
result += freq[prefix - k];
freq[prefix]++;
```

- `freq[0] = 1` 表示数组开始前的空前缀。
- 查询必须在插入当前前缀之前，避免 `k == 0` 时统计空子数组。
- 同一个前缀和可能出现多次，要增加 `freq[prefix-k]`，不能只执行 `result++`。

记忆句：**当前前缀减目标，查以前出现几次。**

## 常见语法陷阱

- `unordered_map<Key, Value>` 必须同时指定 key 和 value 类型；`unordered_set<T>` 只指定元素类型。
- `map[key]` 在 key 不存在时会自动插入默认值；只判断存在性时优先使用 `find` 或 `count`。
- `find` 返回迭代器，确认不等于 `end()` 后再读取 `it->second`。
- 频次问题的 value 是“出现次数”，不能把“存在”误当成“一次”。
