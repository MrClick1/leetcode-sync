# 贪心

## 共性框架

贪心每一步保留当前最合适的选择。关键是说明为什么放弃其他选择不会遗漏最终最优解，而不只是说“当前看起来最好”。

复习时依次说明：当前考虑哪种决策、保留哪个候选、候选如何更新，以及局部最优为什么足够覆盖全局最优。

## 题目清单

| 题目 | 贪心选择 | 关键易错点 | 复杂度 |
|---|---|---|---|
| [55. 跳跃游戏](../2026-09-29/0055-jump-game.md) | 从可达位置不断扩大最远覆盖下标 | 不可达位置不能更新；下标与跳跃长度不同；出现 0 不必然失败 | O(n) 时间 / O(1) 额外空间 |
| [121. 买卖股票的最佳时机](../2026-09-29/0121-best-time-to-buy-and-sell-stock.md) | 固定卖出日，选择此前最低买入价 | 日期顺序不可丢；历史最大利润不能只取最后一天；不交易为 0 | O(n) 时间 / O(1) 额外空间 |

## 55. 跳跃游戏

维护 farthest 表示从已检查的可达位置能覆盖到的最远下标。i<=farthest 才能使用 nums[i]，随后更新 farthest=max(farthest,i+nums[i])；覆盖到 n-1 即成功。允许选择不超过最大长度的步数，因此已覆盖范围内的位置都可达，不必枚举具体路径。

用户版本用临时变量 curMaxLeap 保存 i+nums[i]，且成功判断放在可达 if 外，均正确。可省去临时变量，并在 i>farthest 时提前返回 false。不能把当前位置不可达时的 nums[i] 用来“救回”覆盖范围。

## 121. 买卖股票的最佳时机

每天尝试卖出。对同一个卖出日，买入越便宜，利润越大，其他更贵的历史买入候选都不会更好。因此维护 minPrice 作为此前最低价，res 作为历史最大利润。

```cpp
res = max(res, prices[i] - minPrice);
minPrice = min(minPrice, prices[i]);
```

先用此前最低价计算当天利润，再让今天成为后续的买入候选。res 初始为 0，允许不交易。用户从 i=0 开始的版本已通过，首轮计算为 0；从 i=1 开始也可，后者省去首轮无效计算。

不能直接取整个数组最大值减最小值，较高价格可能在较低价格之前。不能排序价格，也不能把单次交易与多次交易累加上涨利润混用。
