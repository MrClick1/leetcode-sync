# 堆与数据流

## 共性框架

堆适合反复获取当前最大值或最小值：

```text
top() 读取堆顶
push() 加入元素
pop() 删除堆顶但不返回元素
```

默认 `priority_queue<int>` 是大顶堆；小顶堆需要 `greater<int>`。

## 215. 数组中的第 K 个最大元素

用户确认手工大顶堆 + 迭代调整版本通过。建堆 O(n)，移除 k-1 个最大值，每次交换根与当前 len-1、缩小堆、修复根，剩余堆顶即答案。len 每轮已经减小，不要再减循环计数 i。与官方递归下沉相比，操作路径相同，用户版额外空间 O(1)，官方递归栈 O(log n)。

该方法最坏 O(n+k log n)，不满足题面线性时间目标。随机快速选择已讨论，最终修正版通过待确认；重点区分基准归位下标与分界线，及重复值和 l<=r 边界，详见日期笔记。

## 347. 前 K 个高频元素

先用 unordered_map 统计“数字 → 次数”，再将每个不同数字和频次放入大顶堆。pair.first 是数字，pair.second 是频次；比较器返回 a.second < b.second，让高频元素在堆顶。连续 k 次先取 top().first、再 pop()。

当前通过版本逐个入堆，在不同数字很多时达到 O(n log n)；进阶优化尚未学习。比较器 struct + operator() 与 lambda 的语法参见 C++ 语法文档 STL 1.7。

## 295. 数据流的中位数

维护两个堆：

- 大顶堆 `left`：较小的一半，堆顶是左半最大值。
- 小顶堆 `right`：较大的一半，堆顶是右半最小值。

不变量：

```text
left.size() == right.size()
或
left.size() == right.size() + 1
```

因此：

- 总数为奇数：中位数是 `left.top()`。
- 总数为偶数：中位数是两个堆顶的平均值。

求平均值时先转换为 `double` 或更大整数类型，避免两个 `int` 相加溢出。

## 23. 合并 K 个升序链表

小顶堆里保存每条链表当前头节点。每弹出一个最小节点，就把它的后继加入堆。堆大小不超过 `k`，总节点数为 `N`，因此时间复杂度为 `O(N log k)`。

## 小顶堆模板

```cpp
priority_queue<int, vector<int>, greater<int>> minHeap;
```

自定义节点比较器中，返回 `true` 表示左参数优先级更低。要让值小的节点位于堆顶，常写：

```cpp
return left->val > right->val;
```

## 堆题检查清单

- 当前需要快速得到最大值还是最小值？
- 比较器方向是否写反？
- `top()`、`pop()` 前是否检查非空？
- 是否先读取 `top()` 再 `pop()`？
- 插入一个结果后是否需要重新平衡多个堆？
- 堆中保存的是所有元素，还是每个来源的当前候选？
