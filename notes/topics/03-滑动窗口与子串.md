# 滑动窗口与子串

## 先区分概念

- 子串、子数组：元素必须连续，适合用左右边界描述区间。
- 子序列：只保持相对顺序，可以跳过元素，通常不是滑动窗口问题。

滑动窗口的核心不是“两个指针”，而是维护一个可以随着边界移动而增量更新的区间状态。

## 3. 无重复字符的最长子串

使用 `unordered_set<char>` 维护闭区间窗口 `[left, right]` 中出现的字符：

```text
右端尝试加入字符
→ 出现重复时不断删除左端字符
→ 窗口恢复无重复
→ 加入右端字符并更新最大长度
```

关键代码：

```cpp
while (window.count(s[right])) {
    window.erase(s[left]);
    ++left;
}
window.insert(s[right]);
answer = max(answer, right - left + 1);
```

收缩必须使用 `while`，因为旧的重复字符不一定就在窗口最左端。不要把 `right = 0`、访问 `s[right]` 的模板与官方 `right = -1`、访问 `s[right + 1]` 的模板混用。

## 76. 最小覆盖子串

标准流程：

```text
右端扩张 → 更新窗口状态 → 窗口合法 → 记录答案并收缩左端
```

- `need`：目标字符串中每种字符需要多少个。
- `window`：当前窗口中目标字符出现多少个。
- `required`：目标字符种类数。
- `formed`：当前已经满足数量要求的字符种类数。
- 当 `formed == required` 时窗口合法，先记录答案，再尝试移动左端。

关键顺序：删除左端字符前，如果它的数量刚好满足需求，删除后会变成不足，应让 `formed--`；然后减少窗口计数并执行 `left++`。

无解时 `bestStart` 仍为 `-1`，必须返回空字符串，不能调用 `substr(-1, ...)`。

## 32. 最长有效括号

虽然处理的是连续子串，但标准方法是下标栈：

- 栈底保存最近一个不能参与有效括号串的边界，初始放入 `-1`。
- 遇到 `'('` 压入下标。
- 遇到 `')'` 先弹栈；若栈空，当前下标成为新边界；否则用 `i - stack.top()` 更新长度。

栈必须保存 `int` 下标，不能使用 `stack<char>`，否则较大的下标会被截断。

## 窗口题检查清单

1. 左右边界表示闭区间还是半开区间？
2. 右端加入元素后更新了哪些状态？
3. 什么条件代表窗口合法？
4. 合法时先记录答案还是先移动左端？
5. 左端移除元素时，计数和合法状态是否同步更新？
6. 无解、空窗口和重复字符是否单独验证？
