# 二叉树

## 共性框架

递归树题先回答两个问题：

1. 当前函数代表什么？
2. 它应该返回给父节点什么信息？

如果答案依赖左右子树先算出的信息，通常是后序遍历；如果要按根节点顺序重连，可能使用前序遍历或显式迭代。

## 98. 验证二叉搜索树

递归函数接收当前节点允许的开区间：

```text
lower < node->val < upper
```

- 左子树把上界收紧为当前值。
- 右子树把下界收紧为当前值。
- 必须保留所有祖先施加的约束，不能只比较直接父节点。
- 使用严格不等式，重复值不合法。

## 108. 有序数组转换为 BST

- 当前递归负责闭区间 `[left,right]`。
- 选择中点作为根，让左右子树规模尽量接近。
- 左区间为 `[left,mid-1]`，右区间为 `[mid+1,right]`。
- `left > right` 时返回 `nullptr`。

## 114. 二叉树展开为链表

最终进阶版本使用原地迭代：

1. 当前节点存在左子树时，找到左子树最右节点 `pre`。
2. `pre->right` 接回当前节点原来的右子树。
3. 把左子树整体移动到右侧。
4. 当前左指针置空，沿新的右链继续。

目标顺序是原树前序遍历，且所有 `left` 最终为 `nullptr`。

## 437. 路径总和 III

当前根到节点的前缀和为 `sum`，查询当前路径中 `sum-target` 出现了多少次。

```cpp
count += freq[sum - target];
freq[sum]++;
dfs(left);
dfs(right);
if (--freq[sum] == 0) freq.erase(sum);
```

这里的哈希表只能包含当前根到节点路径上的前缀。递归返回时必须回溯，否则左子树记录会污染右子树。

## 543. 二叉树的直径

后序递归同时维护两种信息：

- 返回给父节点：当前节点向下的最大高度 `1 + max(leftHeight,rightHeight)`。
- 更新全局答案：经过当前节点的路径长度 `leftHeight + rightHeight`。

记忆句：**函数向上交高度，节点现场算直径。**

## 树题检查清单

- 空节点返回什么？
- 当前函数返回的是答案、深度、范围还是节点？
- 左右子树调用顺序是否影响指针修改？
- 是否需要使用 `long long` 处理路径和或边界？
- 使用成员变量时，每次入口是否正确初始化？
