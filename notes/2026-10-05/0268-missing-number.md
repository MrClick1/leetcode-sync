# 268 丢失的数字

## 用户实现

```cpp
class Solution {
public:
    int missingNumber(vector<int>& nums) {
        int len = (int)nums.size();
        int res = 0;

        for (int i = 0; i < len; ++i) {
            res ^= nums[i];
        }

        for (int i = 0; i <= len; ++i) {
            res ^= i;
        }

        return res;
    }
};
```

## 两组数字一起异或

完整范围 0..n 包含 n+1 个数字，nums 包含其中 n 个不同数字，缺少的数记为 missing。将两组一起异或，所有已出现的数字恰好出现两次，利用 a^a=0、a^0=a，以及交换律和结合律，最终只剩 missing。

以 nums=[3,0,1] 为例：

```text
(3 ^ 0 ^ 1) ^ (0 ^ 1 ^ 2 ^ 3)
= (3 ^ 3) ^ (0 ^ 0) ^ (1 ^ 1) ^ 2
= 2
```

136 是在同一数组里抵消成对数字；268 则把“实际数组”和“完整范围”放在一起，使每个已出现数字都有对应的另一份。因此不要求数组有序，也不要求相同数字在异或顺序中相邻。不能只异或 nums，它的结果通常不是缺失的数字。

## 边界和复杂度

- 数组下标为 0..n-1，所以第一个循环用 i<len。
- 完整范围是 0..n，所以第二个循环必须用 i<=len，不能漏掉 n。
- 缺失 0 同样成立，例如 nums=[1]，1^0^1=0；缺失 n 也成立，例如 nums=[0,1]，最后剩 2。
- 两个循环顺序执行，分别 n 次、n+1 次，总计 2n+1 次，因此时间 O(n)，不是 O(n²)。
- 只使用 len、res 和循环变量，额外空间 O(1)，不修改输入数组，已经满足进阶要求。

## 官方四种方法对照

依据用户完整贴出的官方题解讲解，沿用同一个例子 nums=[3,0,1]、n=3、完整范围 [0,1,2,3]，不将其他方法标记为用户已经实现或提交通过。

### 方法一 排序后找第一个不对应的位置

排序得到 [0,1,3]。前两个下标与数字一致，到下标 2 时 nums[2]=3 而不是 2，因此缺失 2。因为数字互不相同，缺失数之前没有空缺，排序后的第 i 个数就是 i；遇到第一个空缺时，当前位置的数开始比下标多 1。

若所有位置都对应，例如 [0,1,2]，数组中 0..n-1 都齐全，缺的是 n，最后 return n。不能继续访问 nums[n]，因为该下标超出数组范围。此方法直接 sort(nums.begin(),nums.end())，会改变原数组的顺序。

### 方法二 哈希集合检查谁没来

把数组数字加入 unordered_set，得到 {0,1,3}，再检查 0..3，发现 2 不在集合中就返回 2。这里不用排序，但要为集合付出 O(n) 额外空间。

官解的 set.count(i) 返回键 i 的出现数量：unordered_set 不存重复键，因此是 0 或 1。!set.count(i) 在数量为 0 时为 true，即该数字不在集合中。哈希插入与查询按平均情况为 O(1)，总时间平均 O(n)，不是每次查询在任何情况下都保证常数时间。

### 方法三 异或抵消

这就是用户现有双循环代码。除了 len/n 变量名与显式类型转换外，循环、初始化和返回逻辑与官解相同。无需实际把 0..n 添加进 nums，只需将两组数字依次异或到 res 即可；已出现数抵消，缺失数留下。时间 O(n)，额外空间 O(1)，不修改数组，也不需要计算数值总和。

### 方法四 完整总和减实际总和

完整范围的和 total=0+1+...+n，实际数组的和 arrSum=total-missing，因此 missing=total-arrSum。本例完整和是 6，实际和是 4，差为 2。求和不依赖数组顺序。

把 0..n 正着、倒着各写一遍，每一对的和都是 n，共 n+1 对，所以 2*total=n*(n+1)，即 total=n*(n+1)/2。计算 total 是 O(1)，累加数组仍要 O(n)，因此整个算法不是 O(1) 时间。

本题 n<=10000，乘法中间值最多 10000*10001=100010000，总和为 50005000，32 位 int 足够。若将思路用于更大范围，可从乘法开始使用 long long：

```cpp
long long total = 1LL * n * (n + 1LL) / 2;
long long arrSum = 0;
for (int num : nums) {
    arrSum += num;
}
// 返回 total - arrSum；本题答案在 [0,n] 内，可转为 int。
```

仅把 total 声明为 long long，而右边仍写 n*(n+1)/2，不能防止右侧先按 int 计算时的溢出。上面的提升是更通用的参考，本题原官解的 int 写法在给定范围内没有该问题。

### 复杂度和如何选择

| 方法 | 查找缺失值的方式 | 时间 | 额外空间 | 修改原数组 |
|---|---|---|---|---|
| 排序 | 找第一个 nums[i]!=i 的位置 | O(n log n) | 常见排序实现 O(log n) | 会 |
| 哈希集合 | 检查完整范围中谁不在集合 | 平均 O(n) | O(n) | 不会 |
| 异或 | 两组数字抵消，只留缺失数 | O(n) | O(1) | 不会 |
| 数学 | 完整总和减实际总和 | O(n) | O(1) | 不会 |

排序空间沿用官解对常见排序调用栈的估计，不把它说成所有 sort 实现统一的额外空间保证。异或与数学均满足进阶要求；位运算路线优先巩固现有异或版，再理解数学作差版，无需背下四份代码。记忆区别为“排序找位置、集合查存在、异或做抵消、求和做差值”。

## 可选的单循环参考

双循环已经正确，也更直观，不要求改写。若要合并循环，可以先把额外的 n 异或进去，再在每轮同时处理一个下标与一个数组值：

```cpp
int missingNumber(vector<int>& nums) {
    int n = static_cast<int>(nums.size());
    int res = n;
    for (int i = 0; i < n; ++i) {
        res ^= i;
        res ^= nums[i];
    }
    return res;
}
```

这里的下标仅用来生成完整范围的 0..n-1，不是要求 nums[i]==i；初始 res=n 负责补上范围末尾的 n。两种写法异或的是同一组数，复杂度相同。该版本为助手等价参考，不是另一份用户提交。
