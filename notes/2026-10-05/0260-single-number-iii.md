## 从 136 的抵消继续推导

设两个只出现一次的数字为 a、b。全部元素异或后，成对数字消失，结果 diff=a^b，而不是单独的 a 或 b。不能直接从一个异或值唯一还原两个未知数字。a!=b 保证 diff!=0，其二进制至少有一个 1；这个 1 对应 a、b 不同的某一位。

本例 nums=[1,2,1,3,2,5]：diff=3^5=6。

```text
3    = 0011
5    = 0101
diff = 0110
mask = 0010  （选择从右数第 1 位，最低位编号为 0）
```

## 按一个不同的位分成两组

根据 num&mask 是否为 0 分组。本例选 mask=2，不是按奇偶分组，而是检查第 1 位：

| 条件 | 本例元素 | 分组内异或 |
|---|---|---|
| (num&mask)==0 | 1、1、5 | 1^1^5=5 |
| (num&mask)!=0 | 2、3、2 | 2^3^2=3 |

a、b 在选中的位上不同，因此分别进两组；每一对相同数字的所有位都一样，因此两个副本一定进同一组，仍能抵消。每组恰好剩一个只出现一次的数字，变成两个 136 子问题。

表中的组只是帮助理解，不需要真的建立两个数组或集合。第二次遍历只维护两个 int 异或累计值，初值均为 0；按分组条件将当前数字异或到对应变量。返回两个结果，顺序任意。

## 先用通用取位方法形成编码

第一遍用 int diff=0 累计全部数字的异或。从最低位开始找 diff 中任意一个为 1 的位置，得到分组掩码：

```cpp
unsigned int mask = 1u;
while ((diff & mask) == 0) {
    mask <<= 1;
}
```

diff=0110 时，先检查 mask=0001 没命中，左移成 0010 后命中，循环停止。mask 用 unsigned int，适应可能需要检查符号位的情况；diff 与 mask 做按位与时按无符号类型转换。合法输入保证 diff 非零，不会一直找不到。固定 32 位下至多左移 31 次，无需右移负数。

分组判断使用 `(num & mask) == 0` 或 `!= 0`，不要写 `== 1`：按位与保留的是该位的位权，例如此处命中返回 2，不是 1。括号不能省略为 num&mask==0，因为比较运算优先于按位与。

之前学过的提取最低位 1 技巧也能得到 mask，但先掌握分组原理和通用扫描。完整 int 范围不能直接写有符号 diff&(-diff)：两个单次数字可能是 0 和 INT_MIN，此时直接对 diff=INT_MIN 求负会有符号溢出。后续采用技巧时应使用无符号运算或明确的边界处理。

## 编码顺序与复杂度

1. 第一遍遍历，抵消成对数字，计算 diff=a^b。
2. 找到 diff 中一个为 1 的位，用 mask 记录。
3. 第二遍遍历，按该位为 0 或非 0，分别累计两个结果。
4. 返回两个累计结果。

两个顺序遍历 O(n)，固定 32 位找位 O(1)，总时间 O(n)、常量辅助空间 O(1)。实际建立两个分组数组会变成 O(n) 辅助空间。

记忆句：先异或找不同，再按一位分两组，组内成对抵消。
