# 260 只出现一次的数字 III

题目：[260 只出现一次的数字 III](https://leetcode.cn/problems/single-number-iii/)。

2026-10-05 用户主动进入原位运算路线的第一道进阶题，随后写出分组异或首版，遇到移位未赋值与掩码判断 ==1 两个问题。尚无提交通过反馈；保留首版与排错记录，局部修正为助手参考，不标用户已通过。本题作为位运算补充练习收录。

## 用户首版与排错

```cpp
class Solution {
public:
    vector<int> singleNumber(vector<int>& nums) {
        int n = (int)nums.size();
        int xorsum = 0;
        for (int i = 0; i < n; ++i) {
            xorsum ^= nums[i];
        }

        int mask = 1;
        while ((xorsum & mask) == 0) {
            mask << 1;
        }

        int type1 = 0;
        int type2 = 0;
        for (int i = 0; i < n; ++i) {
            if ((nums[i] & mask) == 1) {
                type1 ^= nums[i];
            } else {
                type2 ^= nums[i];
            }
        }
        return {type1, type2};
    }
};
```

用户报告 [1,2,1,3,2,5] 得到 [6,0]。先计算 xorsum=6=0110；mask=1=0001，按位与为 0，进入 while。mask<<1 只计算 2，没有赋回 mask；每轮 mask 仍是 1，条件始终成立。按贴出的源码逻辑，此例应停在 while，不会正常进入分组。报告的返回值与循环推演不一致，应核对实际运行版本，不把 [6,0] 当成这份完整源码已正常返回的证据。

如果以 mask=1 进入分组，==1 会将奇数 [1,1,3,5] 放入 type1，偶数 [2,2] 放入 type2，得到 [6,0]；此时 3、5 没有被分开。这是条件分组模拟，不是认定贴出的 while 能正常执行完。

第一处修正是移位赋值，沿用无符号掩码：

```cpp
unsigned int mask = 1u;
while ((xorsum & mask) == 0) {
    mask <<= 1;  // 等价于 mask = mask << 1
}
```

修正后本例 mask=2=0010。第二处 ==1 仍有问题：num&2 只能得到 0 或 2，不可能得到 1，所有数字都会进入 type2，结果为 [0,6]。按位与保留的是位权，不是归一化的 0/1。应该判断是否非零：

```cpp
if ((nums[i] & mask) != 0) {
    type1 ^= nums[i];
} else {
    type2 ^= nums[i];
}
```

此时 type1 的 [2,3,2] 抵消得 3，type2 的 [1,1,5] 抵消得 5，返回 [3,5]。复习区别：x<<k 是表达式，x<<=k 更新变量；取某一位是否存在用 (x&mask)!=0，只有取最低位 x&1 或先右移再&1 时才自然得到 0/1。

本轮只对这个示例做 JavaScript 有界模型：前三次未赋值移位，mask 均为 1；另核对 mask=1 的原分组得 [6,0]、只修移位后 mask=2 仍 ==1 得 [0,6]、两处修正后得 [3,5]。没有运行无界错误循环或新增 C++ 编译，也没有用户通过反馈。首次引导的 168 个输入概念验证另行保留。

## 从 136 的抵消继续推导

设两个只出现一次的数字为 a、b。全部元素异或后，成对数字消失，结果 diff=a^b，而不是单独的 a 或 b。不能直接从一个异或值唯一还原两个未知数字。a!=b 保证 diff!=0，其二进制至少有一个 1；这个 1 对应 a、b 不同的某一位。

本例 nums=[1,2,1,3,2,5]：diff=3^5=6。

```text
3    = 0011
5    = 0101
diff = 0110
mask = 0010  （选择从右数第 1 位，最低位编号为 0）
```

## 按一个不同的位分成两组

根据 num&mask 是否为 0 分组。本例选 mask=2，不是按奇偶分组，而是检查第 1 位：

| 条件 | 本例元素 | 分组内异或 |
|---|---|---|
| (num&mask)==0 | 1、1、5 | 1^1^5=5 |
| (num&mask)!=0 | 2、3、2 | 2^3^2=3 |

a、b 在选中的位上不同，因此分别进两组；每一对相同数字的所有位都一样，因此两个副本一定进同一组，仍能抵消。每组恰好剩一个只出现一次的数字，变成两个 136 子问题。

表中的组只是帮助理解，不需要真的建立两个数组或集合。第二次遍历只维护两个 int 异或累计值，初值均为 0；按分组条件将当前数字异或到对应变量。返回两个结果，顺序任意。

## 先用通用取位方法形成编码

第一遍用 int diff=0 累计全部数字的异或。从最低位开始找 diff 中任意一个为 1 的位置，得到分组掩码：

```cpp
unsigned int mask = 1u;
while ((diff & mask) == 0) {
    mask <<= 1;
}
```

diff=0110 时，先检查 mask=0001 没命中，左移成 0010 后命中，循环停止。mask 用 unsigned int，适应可能需要检查符号位的情况；diff 与 mask 做按位与时按无符号类型转换。合法输入保证 diff 非零，不会一直找不到。固定 32 位下至多左移 31 次，无需右移负数。

分组判断使用 `(num & mask) == 0` 或 `!= 0`，不要写 `== 1`：按位与保留的是该位的位权，例如此处命中返回 2，不是 1。括号不能省略为 num&mask==0，因为比较运算优先于按位与。

之前学过的提取最低位 1 技巧也能得到 mask，但先掌握分组原理和通用扫描。完整 int 范围不能直接写有符号 diff&(-diff)：两个单次数字可能是 0 和 INT_MIN，此时直接对 diff=INT_MIN 求负会有符号溢出。后续采用技巧时应使用无符号运算或明确的边界处理。

## 编码顺序与复杂度

1. 第一遍遍历，抵消成对数字，计算 diff=a^b。
2. 找到 diff 中一个为 1 的位，用 mask 记录。
3. 第二遍遍历，按该位为 0 或非 0，分别累计两个结果。
4. 返回两个累计结果。

两个顺序遍历 O(n)，固定 32 位找位 O(1)，总时间 O(n)、常量辅助空间 O(1)。实际建立两个分组数组会变成 O(n) 辅助空间。

记忆句：先异或找不同，再按一位分两组，组内成对抵消。
