## 用户通过代码：清掉最低设置位

```cpp
class Solution {
public:
    int count1(const int& n) {
        int m = n;
        int res = 0;
        while (m) {
            m = m & (m - 1);
            ++res;
        }
        return res;
    }

    vector<int> countBits(int n) {
        vector<int> dp(n + 1, 0);
        for (int i = 1; i <= n; ++i) {
            dp[i] = dp[i & (i - 1)] + 1;
        }
        return dp;
    }
};
```

dp[i] 表示整数 i 的二进制中 1 的个数。i&(i-1) 恰好清掉最右边的一个 1，因此当前数比清位后的数多一个 1：

```cpp
dp[i] = dp[i & (i - 1)] + 1;
```

例如 12=1100，清位后为 8=1000，dp[12]=dp[8]+1=2。13=1101，清位后为 12，dp[13]=dp[12]+1=3。

## 用户通过代码：右移并补回末尾位

```cpp
class Solution {
public:
    int count1(const int& n) {
        int m = n;
        int res = 0;
        while (m) {
            m = m & (m - 1);
            ++res;
        }
        return res;
    }

    vector<int> countBits(int n) {
        vector<int> dp(n + 1, 0);
        for (int i = 1; i <= n; ++i) {
            dp[i] = dp[i >> 1] + (i & 1);
        }
        return dp;
    }
};
```

i>>1 去掉最右边的一位，i&1 取得被去掉的这一位。它可能是 0，也可能是 1，因此不能固定加 1：

```cpp
dp[i] = dp[i >> 1] + (i & 1);
```

12=1100 和 13=1101 右移后都是 6=110；前者补 0，后者补 1，得到计数 2 和 3。(i&1) 保留括号，加法的优先级高于按位与。

## 与原来逐个统计的区别

原 count1(13) 需要自己执行 13->12->8->0，共三轮清位。DP 清位法只执行 13->12 这一轮，再读取已经算好的 dp[12]，不再重复计算 12 的答案。

两种 DP 的依赖下标都小于 i：正数清掉一个 1 后变小，非负数右移一位也变小。因此从 1 到 n 正序遍历即可，dp[0]=0 是共同起点。n=0 时不进入循环，返回 [0]。

两份通过代码中的 count1 已没有被调用，可以删除整个辅助函数；保留它不会让 countBits 增加循环，也不会将 DP 的时间复杂度变回 O(n log n)。上方保留用户原代码，删除 helper 仅为简化建议，不作为另一份用户提交记录。

## 复习时怎么记

先说明“去掉了什么”，再决定“补回多少”：

- 清掉一个 1 -> 查清位后的答案，固定补 1。
- 去掉末尾一位 -> 查右移后的答案，补末尾位的值 0/1。

不要只背括号里的表达式。练习不看代码解释 12 和 13 的两种转移，以及为什么正序遍历能够查到已算好的状态。官解方法二最高有效位目前只作学习参考，未记录为用户独立实现通过。
